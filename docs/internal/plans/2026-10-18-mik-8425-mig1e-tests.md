# MIK-8425 MIG.1e-2 to MIG.1e-9: route the test-only src files (series plan)

Status: for review before any code, 2026-10-18. Refs MIK-8425. Parent:
`docs/internal/design/2026-10-17-mik-8425-yaml-migration.md` (row 7,
MIG.1e: "plus the test-only files that use serde_yaml", split to stay at
15 paths or fewer), the adapter (#3922), MIG.1e-1 (#3945). This plan is
reviewed once for the whole series, and it lands in the first batch's PR
(branch `feat/mik-8425-mig1e2-tests-b1`, cut from the line tip fd47f6bd2).
Each later batch PR cites it and gets its own code review.

## Goal

Route the 95 test-only `src/` files still on the bypass allowlist through
`crate::yaml`, in 8 batches. There is no behaviour change in any product
path: every file is a test module or test fixture. The files leave the
allowlist batch by batch. After B8, the only `src/` row left is
`src/yaml.rs` itself; the 52 `tests/` rows are MIG.1f.

## Inventory (on fd47f6bd2)

- **Set:** the allowlist on fd47f6bd2 has 102 `src/` rows. Leave out
  `src/yaml.rs` and the 6 MIG.1e-1 files (#3945, open):
  `config/config_file.rs`, `config/load_error.rs`,
  `config/tests/load_error.rs`, `commands/backend_url_keys.rs`,
  `commands/doctor/hidden_keys.rs`, `commands/doctor/hidden_keys_tests.rs`.
  That leaves 95.
- **Items:** 219 `serde_yaml` mentions: 216 uses of items the adapter
  already has (`from_str` 180, `to_string` 23, `Value` 8, `from_value` 2,
  `Mapping` 1, `Error` 1, `to_value` 1), and 3 in comments. No
  `use serde_yaml` block. No figment `Yaml` use.
- **Change:** a pure path rename from `serde_yaml::` to `crate::yaml::`.
  Three files name `serde_yaml` only in a comment, and those comments are
  reworded to "the YAML parser": `capability/validator/tests/yaml_roundtrip.rs`,
  `commands/protocol_import_tests.rs`, `identity_grants_agent_key_tests.rs`.
  A test name containing `_serde_yaml` (an identifier character before it,
  so not matched by the gate) keeps its spelling.
- **Binary crate:** `commands/protocol_import_tests.rs` and
  `commands/upgrade/tests.rs` (B2) are in the binary crate, where
  `src/main.rs:49` declares `mod yaml`; their tests run with
  `--bin mcp-gateway`.
- **Size cap:** three files are near the 800-line ceiling:
  - `gateway/meta_mcp/invoke/relay_tests.rs` (799, B4);
  - `gateway/webhooks/tests.rs` (796, B7);
  - `events/upstream_session_tests.rs` (781, B3).

  The rename adds one character per site, and rustfmt can wrap a line. If
  any of them would pass 800, that file takes `use crate::yaml;` and calls
  `yaml::from_str`, which is shorter than the old spelling. It is not split.

## Per batch (red first)

- **R1, red:** remove the batch's files from
  `tests/fixtures/mik_8425_yaml/direct_users.txt`. T5
  (`cargo test --test mik_8425_yaml_adapter no_new_file_names_a_yaml_parser_directly`)
  must fail and list exactly those files. After routing it passes.
- **R2, unchanged behaviour:** the existing tests in the routed files are
  the oracle. Each runs by a module filter covering its files, with a
  positive passed count, so a filter matching nothing cannot pass: lib for
  library files and `--bin mcp-gateway` for `commands/`. Also run the
  adapter and MIG.0 golden suites. Each batch PR lists its exact filters
  and passed counts. Two files hold no `#[test]` of their own:
  - `key_server/oidc_harness_tests.rs` (B7) is the module
    `key_server::oidc_test_harness`. It runs through its users,
    `key_server::identity_rules_tests` and `gateway::server::tools_changed`.
  - `gateway/router/sso_admin_tests.rs` (B5) holds the child modules
    `cells`, `admin_action` and `dashboard_link`. It runs through the filter
    `gateway::router::sso_admin_tests`.
- **R3:** clippy `-D warnings` of `--lib --tests --bins` on all-features
  and no-default, `check-file-size.py` and `check-timing-asserts.py`.
- **Gate:** one full pre-push gate on the routed head. If the line moves
  afterwards with disjoint PRs, run targeted checks per the lead's ruling.
- **Order:** one MIG PR open at a time, while macOS CI is capped (lead,
  2026-10-18). Each batch is cut from the line tip after the previous one
  merges, so the allowlist never conflicts within the series.
