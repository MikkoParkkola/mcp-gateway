## Order of work

1. Ten review shards return; confirmed findings are repaired one commit per finding.
2. CI triaged and green.
3. Operator decisions land: alerts #92/#97/#100, #78 fix-or-accept, R35 wording.
4. Scratch files removed from the release.

6. DoD evidence comment posted, acceptance criteria table included.
7. Merge, then §P5 housekeeping — branch, worktree, tracking issues.
