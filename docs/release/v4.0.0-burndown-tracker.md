Clearing the last two lints surfaced one warning CI had never reached: a lib-only
clippy pass after the refactor reported `src/commands/accounts.rs:24:34 -- this
argument is passed by value, but not consumed in the function body`. The binary
target only became reachable once the library compiled clean. That is the
fail-fast effect at work again, and it is why the total below is a floor rather
than a ceiling. Fixed by taking the argument by reference.

46 -> >=167 -> 2 -> 0. The middle number was never a regression: it was the local
`--all-targets` view of errors the narrower CI gate could not see. CI's own gate
(`cargo clippy --all-features`, lib only) is now two errors from green.

The gate is being widened to `cargo clippy --all-targets --all-features -- -D
warnings`, because a release gate that never lints test code grades a subset of
what ships. That is a superset of both prior gates, not a restoration of either:
`CLAUDE.md` documents `--all-targets` on default features, CI shipped
`--all-features` on the library alone, and the new line is the union. That raises the CI floor to roughly the local
`--all-targets` number before it falls to zero. Widening the gate and clearing it
are tracked as one step, so the branch is never green against a gate weaker than
the documented one.

The rise from 46 to >=167 is the fail-fast effect being paid off, not a regression:
errors that were always present became visible once the layer above them compiled.

This total is a floor that can RISE, not a burndown ceiling. CI compiles fail-fast:
while the library fails, no integration-test target is built, so its errors are not yet
in any job log. Clearing one layer reveals the next — measured, not predicted: after the
`personal_accounts` dead-code fix let the library compile, `cargo check --all-targets`
surfaced 5 previously invisible errors in `tests/task_upstream_recovery/helper.rs`.
Expect the number to grow before it shrinks.


## How to regenerate this number

```sh
f=docs/requirements/RELEASE-4.0.0-criteria-status.md
total=$(rg -c '^\| *(MIK-|[A-Z][A-Z0-9]+\.)' $f)
met=$(rg -c '^\| *(MIK-|[A-Z][A-Z0-9]+\.).*\| *MET' $f)
echo "core: $((total-met)) open of $total"
jq -r '.criteria[].status' docs/requirements/RELEASE-4.0.0-scope-status.json \
  | sort | uniq -c
```
