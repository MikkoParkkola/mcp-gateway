## How to regenerate this number

```sh
f=docs/requirements/RELEASE-4.0.0-criteria-status.md
total=$(rg -c '^\| *(MIK-|[A-Z][A-Z0-9]+\.)' $f)
met=$(rg -c '^\| *(MIK-|[A-Z][A-Z0-9]+\.).*\| *MET' $f)
echo "core: $((total-met)) open of $total"
jq -r '.criteria[].status' docs/requirements/RELEASE-4.0.0-scope-status.json \
  | sort | uniq -c
```
