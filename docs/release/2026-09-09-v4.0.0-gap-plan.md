## What "release ready" means here

All eleven rows MET, each with the evidence its criterion names, and the count
script reporting `0 blocking` with no warnings. Every row goes through the
process it earns: a design where it changes what the thing should BE, a test
plan and failing tests before implementation, two code review legs plus one
functional leg. A row marked MET without an executed test is not met — that is
the failure mode this ledger exists to deny.
