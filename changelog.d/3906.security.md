- **On stdio with message signing, a tool hidden from the caller can no longer be told apart by its error-rate cooldown.** On a per-user backend, a signed `gateway_invoke` of a tool the caller's own list hides answered "temporarily disabled due to a high error rate" when other callers had pushed that tool into cooldown, while a missing name answered "Unknown tool"; the difference showed the hidden name exists. The hidden tool now gets the missing name's answer and is never sent. A caller who can see the tool is still refused for the cooldown, now after its nonce is checked. (MIK-8433)
  Affects: signed `gateway_invoke` calls to per-user backends, on stdio and, when the caller's own list has not shown the tool for that call, on `/mcp`.
  Operator action: none; see UPGRADING (MIK-8433).
- **A caller with no connected account can no longer tell a per-user tool exists from its error-rate cooldown.** On a per-user backend, `gateway_invoke` of a tool other callers had pushed into error-rate cooldown answered "temporarily disabled due to a high error rate", naming the tool, while a missing name got the account's connect offer. On a per-user backend the error-rate check now runs after the caller's credential step, so a caller with no connected account gets the connect offer for both, on `/mcp` and stdio, signed or not, in a task or a `gateway_execute` chain. A caller who can see the tool is still refused for the cooldown. (MIK-8439)
  Affects: callers of per-user backends whose tools enter error-rate cooldown.
  Operator action: none; see UPGRADING (MIK-8439).
