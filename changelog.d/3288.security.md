- Cost accounting no longer keeps one record per answered call. Per-key and per-session spend grew without limit, and a caller without a credential (authentication off, or `/mcp` public as in the shipped presets) could grow gateway memory once per request. Keys, sessions and session-less callers now keep running sums: at most 721 hourly buckets for a key's windows, and per-tool rows capped at 256 plus one `(other)` row. A key idle for 30 days with no set budget is dropped (MIK-8000).
  Affects: the 4.0.0 pre-releases and 3.x. Operator action: none. Key cost windows (24h, 7d, 30d) are now accurate to the hour, and a per-tool breakdown past 256 distinct tools shows the rest as `(other)`.
