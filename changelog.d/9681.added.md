- **Help, completions, man page and version follow one pattern.** Every command's help ends with an example that runs as written, and a mistyped command suggests the closest one. `tool completions` writes scripts for bash, zsh, fish and PowerShell that complete every command, flag and closed value list, tool names included. Releases ship a signed man page, `mcp-gateway.1`, which the Homebrew formula installs. `--version` prints the UI API version beside the CLI version, and `GET /ui/api/status` serves the same number as `ui_api_version`. The tls commands take `--output`, keeping `--out` as a hidden alias.
  Affects: completion scripts written before this release (regenerate them); `tool completions elvish`, no longer offered; anything that parses `--version` output.
