- Capability calls, OpenAPI/UI spec imports and capability discovery no longer follow `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY`, which let a proxy bypass the gateway's SSRF checks; a new `capabilities.egress_proxy` key names a proxy explicitly (UPGRADING item 77). (#1881)
  Affects: 2.6.0 up to 3.5.1 and the 4.0.0 pre-releases. Operator action: set `capabilities.egress_proxy` if capability calls must go through a proxy, since `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY` no longer apply; a spec import that could only reach its spec through a proxy is downloaded and imported from a file instead (UPGRADING-4.0 item 77).
