- **A withheld task notification names the check that withheld its output.** A task-status notification whose stored output is withheld because a check refused it (a tool policy published after the task ran, the key's scope, a descriptor block, a broken schema, provenance) now records that check in its delivery record's `refused_by`: the kind, and the rule id when a configured rule decided. A notification withheld for any other reason records none, and the frame a subscriber gets is unchanged. (MIK-9191)
