- MCP Events: a REST watch subscription whose capability is removed, becomes side-effecting, or moves to another credential class is now held instead of deleted. Its poller makes no call while the subscription is held and resumes it when the capability is watchable again. A held watch keeps its sharing class and key across restarts, and a refused credential still ends the subscription. (MIK-8122)
  Affects: 4.0.0 pre-releases only; 3.x has no MCP Events. Operator action: none.
