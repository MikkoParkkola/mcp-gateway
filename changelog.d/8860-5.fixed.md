- **A crashed gateway.yaml write that a reload recovers is now recorded in the audit log.** On a gateway with an audit log, the reload that finds a crashed write's journal (from the file watcher, an admin reload or the meta-tool, in HTTP or stdio mode) now records a `config_recovery_intent` event before it recovers the file. It used to recover without an audit entry. With auth off and no audit log, recovery is unchanged. (MIK-8860)
