- **A config write the loader would refuse now creates no secret entry.** The shared gateway.yaml writer loads and checks the new file, with a stand-in for each secret, before it saves any secret to the store, so a refused save never adds store entries. A new bearer token that is already an API key's credential is refused the same way. A discovery adopt on a gateway with an audit log records its intent in the log before writing. (MIK-8860)
