- **A `gateway.yaml` value can no longer forge a line in the stdio log.** When `serve --stdio` cannot start, its error is escaped like every other log line.
- **A gateway that cannot start always says why.** Over stdio and HTTP, if the log filter hides the error (`--log-level off`, for example), it is still printed once to stderr, escaped.
- **Two serve warnings follow the log level.** The missing `--config` warning over stdio and the upgrade-check warning are now log lines.
- **Unreachable or unprintable server names are refused at load.** A server name or `capabilities.name` that is `.` or `..` or holds a control character stops the start with an error naming it escaped. Adding such a server in the web UI answers 422, not 500. See `docs/UPGRADING-4.0.md`.
