- **Each server has its own page, with Status and Actions tabs.** A server's name in Servers › Status now links to `/ui/servers/<name>/status`. Status shows the server's state badge and banner, its transport, whether it is running, its tools and its calls in the last 24 hours, a line when it accepted credentials in cleartext, and a link to its calls in Activity; it follows the live status without a new read. Actions offers Restart (Retry now while the server is paused), Sign in again for a server that signs in (the provider's page opens in a new tab; Finish or Cancel completes it), and Remove, whose confirmation counts the tools that disappear, names up to three of the keys that reach the server and counts the rest, and says how often it was called. Every name in an address or request is percent-encoded by one shared module. The Settings tab follows in a later change. (MIK-9570)
