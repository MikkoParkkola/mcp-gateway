- **Audit pages no longer skip records when the log rotates mid-read.** The governance audit, Activity, the Overview's recent actions, Activity's seek and the control-plane export each worked out which log segment to read and how long it was before opening it. A rotation in between could leave a page reading a sealed segment only up to the length of the new, shorter live file, silently skipping every record above that point. Each reader now opens the segment through one shared opener and takes the page's end from the file it actually opened. A cursor into a segment no longer kept, which the governance audit used to answer as the end of the log, now restarts at the newest record with `cursor_reset` set, as Activity already did. A segment that disappears while a page reads it, or a hole between kept segments, fails the page instead of being stepped over. The check behind `audit verify`'s refusal of a hash-only pass over a signed log also re-reads the log when it rotates during the scan, so a signed segment sealed mid-scan is no longer missed. (MIK-8996)
  Affects: anyone paging the governance audit or Activity while the log rotates. Operator action: none.
