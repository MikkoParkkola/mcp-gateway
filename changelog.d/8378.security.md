- **A control character can no longer rename a key the gateway reads inside a meta tool's
  arguments.** Input sanitizing stripped control characters from those keys, so `ser\u0007ver`
  became `server` and a `_fu\u0007ll` inside `gateway_invoke`'s tool arguments became the `_full`
  directive. On `/mcp` and stdio, such a key is now refused with `-32600`. This covers a meta
  tool's own argument keys (an object or a JSON string), each `gateway_execute` chain step's keys,
  `gateway_invoke`'s `_meta` keys, and keys that clean to `_full` or `_claim` inside its tool
  arguments. Other keys in tool arguments are the tool's data and keep today's stripping;
  `/mcp/{name}` is unchanged. (MIK-8378)
  Affects: clients that send control characters inside meta-tool argument keys.
  Operator action: none.
