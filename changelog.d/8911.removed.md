- **The per-key rolling budget that nothing enforced.** For library users, `cost_accounting::BudgetConfig`, `BudgetStatus`, `CostTracker::set_key_budget`, `CostTracker::check_budget`, `KeyCost::budget_status` and the `KeyCost.budget` field are removed. No config key or endpoint set a per-key rolling limit, and nothing checked one, so a key's report always read "no limit, Ok". The cost report's fields are unchanged: `hard_limit_usd` stays `null` and `budget_status` stays `"Ok"`, documented as judging no limit. The enforced per-key daily caps are the budget enforcer's.
