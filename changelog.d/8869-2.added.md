- **The web UI's Overview read now carries calls, flows, markers and server problems.** `GET /ui/api/overview` adds the 24-hour call, block and error totals, with the previous 24 hours when counting covers them; ranks the 24 servers it lists by calls, each with its operator state and reason; adds the top 48 caller and server flows and the chart markers of the last day; and adds needs-you rows for a refused config reload (`invalid_config`), for refused edits and for servers the runtime policy denies (`refused`), plus whether any tool has been called in 30 days. The counter fields are left out when there is no counter store, and named in `degraded` when the clock cannot be read. (MIK-8869)
