- **Web UI: Activity › Status shows the call stream.** The new UI's Activity page lists recent calls, newest first, with an Outcome filter, a search by tool or trace id, and a time range shared with the rest of the page; each row is a keyboard-reachable link to the call, and more rows load as the list scrolls to its end. Links such as "all github calls" or "every call from support-agent" open the list already filtered. An empty range shows one line and the one next step (a longer range). A key that sees only its own calls is told so in one line. (MIK-9553)
