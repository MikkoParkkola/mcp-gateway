- **A hardened pairing re-pins backends already started.** An embedder that started an HTTP or
  WebSocket backend before pairing its registry with a hardened config (`ReloadContext::new`)
  kept an unpinned transport. Pairing now retires it, and the next use rebuilds it under the
  hardened destination policy; a start racing the pairing is refused rather than published.
  The shipped binary pairs before any backend starts and is unaffected. (#2597)
