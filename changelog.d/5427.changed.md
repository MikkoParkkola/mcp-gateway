- **A web UI write refused before anything was attempted answers 409.** Key create, key revoke,
  the backend routes, the config restore, discovery adopt and the settings save answered 503 (or
  500) when they refused a write without attempting it: another write held the config or a
  capability lock, no audit log was configured, gateway.yaml could not be loaded, reload was off,
  or the writer refused gateway.yaml before changing it. A 5xx says the outcome is not confirmed;
  these now answer 409 with the same body, and `Retry-After: 1` only when the refusal clears by
  itself. A timeout or an unavailable dependency keeps its 503, and an audit log that refused an
  append it had started keeps its 5xx. See `docs/UPGRADING-4.0.md`.
