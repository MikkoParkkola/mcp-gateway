- Relay detection under `block` no longer refuses, now and then, a caller forwarding its own
  copy of a source's content when that copy reached it in a different shape (for example split
  over short fields). Which fingerprints are kept near the edges of a copy depends on the text
  around it, so the caller's receipt could miss one that the forward and another caller's receipt
  both held. A fingerprint is now also excused when the caller holds the text within one
  fingerprint window of it. A copy it was never delivered is still refused. (MIK-8083)
  Affects: 4.0.0 pre-releases only; 3.x has no relay detection. Operator action: none.
