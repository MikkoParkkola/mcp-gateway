- **`x-mcp-header` mirroring covers nested and non-ASCII arguments.** An annotated property inside a nested object argument is now mirrored onto its `Mcp-Param-*` header, and a string value that is not plain visible ASCII (a space, a control character, non-ASCII text) is sent Base64-wrapped in the gateway's `=?base64?…?=` header form instead of raw or dropped; an empty value is sent as an empty header. A tool whose nested `x-mcp-header` annotations are invalid or repeat a header name is left out of `tools/list`, as a top-level one already was. A `tools/call` through the router to a backend whose tool list was never fetched still carries its mirror. Carried from #4771 by terafin. (MIK-9425)
