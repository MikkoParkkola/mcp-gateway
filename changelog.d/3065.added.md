- MCP events: `watch.<capability>.changed`, off by default (`events.sources.rest_watch`). An API-key caller can watch a read-only REST capability; the gateway polls it every `interval` seconds (default 300, 60 to 3600) through the same controls as a tool call and emits when the answer changes. The payload names the changed JSON pointers and digests, never values. Credential-free capabilities share one poller per arguments; credentialed ones poll per principal under that principal's key; capabilities that need a per-user account are refused with -32014. (#3065, MIK-7720)
