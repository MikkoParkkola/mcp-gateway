- Callers that authenticate with an API key can create tasks again when authentication is on. Task creation was refused with -32600 "task creation requires a verified caller identity" unless the caller carried an OIDC identity, which no API-key caller does. The task is now owned by the caller's credential, the same owner `tasks/get` and `tasks/cancel` already used, so another key is still told the task does not exist and a caller with no credential is still refused. (#3092, MIK-7967)
