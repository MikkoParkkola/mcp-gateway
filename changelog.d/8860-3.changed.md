- **A web UI save or discovery adopt that stores secrets now refuses two oversized cases before writing anything.** A secret store reference longer than 32 KiB is refused ("the secret store returned a reference longer than the writer allows"). A new gateway.yaml that could pass the loader's 16 MiB limit once its secrets are filled in is refused before any secret is stored ("the new config could grow past the largest file the loader reads once its secrets are filled in"). That check counts each secret at its longest quoted form, about 128 KiB per secret. Either way, any store entries the save created are removed and gateway.yaml is unchanged. (MIK-8860)
