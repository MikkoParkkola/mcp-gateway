- **The web UI can list MCP servers named in other apps' config files on this host.** `GET /ui/api/discovery` (admin only) returns the servers found in client config files (Claude, Cursor, VS Code, Windsurf, Zed, Continue, Codex and `~/.config/mcp`), each with its program name or URL origin, its env and header key names (values are never shown), the file it came from, whether it is already a backend, and whether it could be adopted, with each reason it could not. No network is scanned. Results are cached for 30 seconds and refreshed early when a client file changes; the cache holds no values. (MIK-8859)
