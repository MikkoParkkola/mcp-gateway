- **Web UI saves, key creation and key revocation work on a config file with a YAML document frame.** A `gateway.yaml` that starts with `---`, a byte order mark, or `%YAML`/`%TAG` directives, or ends with `...`, was refused whole by the in-place editor, so no UI save could touch it and a key in it could only be revoked by hand. Every single-document form the config loader accepts now takes in-place edits: the frame's bytes are kept exactly, and every line number in a refusal or hand-edit instruction is the line in the file as written. When the `---` line itself carries the document's root (an inline `--- {...}`, or an anchor or tag such as `--- &root`), an edit to a value under that root is refused for that one field, as it is in a file with no `---`; a key under such a root can still be revoked. Two documents, content after `...`, a directive inside the document and a bare carriage return are still refused.
