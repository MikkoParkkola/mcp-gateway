- **Web UI saves, key creation and key revocation work on a config file with a YAML document frame.** A `gateway.yaml` that starts with `---`, a byte order mark, or `%YAML`/`%TAG` directives, or ends with `...`, was refused whole by the in-place editor, so no UI save could touch it and a key in it could only be revoked by hand. Every single-document form the config loader accepts now takes in-place edits: the frame's bytes are kept exactly, and every line number in a refusal or hand-edit instruction is the line in the file as written. An edit that would rewrite a `---` line which also holds document content (for example `--- {...}`) is refused with that reason. Two documents, content after `...`, a directive inside the document and a bare carriage return are still refused.
