- **A stdio request after the backend's stdout closed fails at once.** Before, it could wait out its whole timeout. The request's write now shares that timeout too, so a backend that stops reading stdin no longer hangs a call. (MIK-7871, #3531)
- **Stdio backends get an absolute npm cache path when `MCP_GATEWAY_CONFIG_DIR` is relative.** A backend with its own `cwd` used to get a path that pointed somewhere else, so the npm cache repair cleared the wrong directory. (MIK-7964, #3531)
