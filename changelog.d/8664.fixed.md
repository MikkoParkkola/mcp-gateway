- **Saved state files keep the mode you set, and `~` follows one rule.** Cost totals, the skills registry, the SIEM export cursor, the upgrade stamp and protocol-import drafts are written through one atomic writer that never leaves a file wider than you set it (owner bits only where an ACL or another group could widen it); they used to reset a chmod on every save. `~` now means your home only as `~` or `~/...`: `~//x` no longer resolves to `/x` in the server and credential path settings, `~user/...` in `env_files` is no longer read under your own home, and with no home directory the transparency log is written where its exporter reads it, with a warning naming the path. (MIK-8664)
