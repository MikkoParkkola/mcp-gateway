- **The gate-day client run now works beside a running gateway.** The release procedure's BUILD.1 client step gives its verify gateway its own task store and its own HOME, so it no longer collides with, or reads the data of, the operator's running gateway. It checks the `claude` login first with `claude auth status`, which makes no model call, and pins the client with `DISABLE_AUTOUPDATER=1`. The run's record names the client version that actually ran. Its PASS check now requires the client's own `gateway_list_servers` call to have succeeded with a non-empty result, read from the client's stream-json output. (MIK-8602)
  Affects: the release procedure only; no shipped file changes.
  Operator action: none.
