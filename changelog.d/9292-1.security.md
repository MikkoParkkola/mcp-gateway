- **Secrets typed into the backend panel are kept out of gateway.yaml.** Adding or editing a backend in the web UI now saves each literal env value, and a registry server's token, in the secret store, and writes only the store's reference to gateway.yaml. The answer lists each stored field and its reference. A value that mixes literal text with a template, or a template with a default, is refused by field in the panel and in `mcp-gateway add`. Values saved before 4.0.0 are not moved; type them again in the panel or replace them with a reference. (MIK-9292)
