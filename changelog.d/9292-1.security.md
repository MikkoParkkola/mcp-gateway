- **Credentials typed into the backend panel are kept out of gateway.yaml.** Adding or editing a backend in the web UI now saves a registry server's token, and each literal env value whose name marks a credential (a `_`-separated part such as `KEY`, `TOKEN`, `SECRET`, `PASSWORD`, `AUTH`; `API_KEY`, `DB_PASSWORD`), in the secret store, and writes only the store's reference to gateway.yaml; adopting a discovered server stores by the same rule. Other env values (`DEBUG=1`) are written as typed, since a stored value is redacted from tool results wherever it appears. The answer lists each stored field and its reference. A value that mixes literal text with a template, or a template with a default, is refused by field in the panel and in `mcp-gateway add`. Values saved before 4.0.0 are not moved; type them again in the panel or replace them with a reference. (MIK-9292)
  Affects: 2.10.0 up to 3.5.1 and the 4.0.0 pre-releases. Operator action: type again in the panel, or replace with an `env:` or `keychain:` reference, any secret the panel saved into gateway.yaml before 4.0.0; write a value that mixes literal text with a template as a whole template or a secret reference.
