- **Secrets typed into the backend panel are kept out of gateway.yaml.** Adding or editing a backend in the web UI now saves each literal env value, and a registry server's token, in the secret store, and writes only the store's reference to gateway.yaml. This covers every plain value, not only secrets (`LOG_LEVEL=debug` is stored too); edit gateway.yaml directly to keep a value as text. The answer lists each stored field and its reference. A value that mixes literal text with a template, or a template with a default, is refused by field in the panel and in `mcp-gateway add`. Values saved before 4.0.0 are not moved; type them again in the panel or replace them with a reference. (MIK-9292)
  Affects: 2.10.0 up to 3.5.1 and the 4.0.0 pre-releases. Operator action: type again in the panel, or replace with an `env:` or `keychain:` reference, any secret the panel saved into gateway.yaml before 4.0.0; write a value that mixes literal text with a template as a whole template or a secret reference.
