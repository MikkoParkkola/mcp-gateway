- **Credentials typed into the backend panel are kept out of gateway.yaml.** Adding or editing a backend in the web UI now saves a registry server's token, and each literal env value whose name ends in a credential word (`DB_PASSWORD`, `X_AUTH_TOKEN`, `GITHUB_PAT`, `OPENAI_API_KEY`; a name that only contains one, such as `TOKEN_LIMIT`, stays text), in the secret store, and writes only the store's reference to gateway.yaml; adopting a discovered server stores by the same rule. Other env values (`DEBUG=1`) are written as typed, since a stored value is redacted from tool results wherever it appears. The answer lists each stored field and its reference. A value that mixes literal text with a template, or a template with a default, is refused by field in the panel and in `mcp-gateway add`. Values saved before 4.0.0 are not moved; replace each with a reference under the same key. (MIK-9292)
  Affects: 2.10.0 up to 3.5.1 and the 4.0.0 pre-releases. Operator action: replace with an `env:` or `keychain:` reference under the same key any secret the panel saved into gateway.yaml before 4.0.0, and any secret under a name the rule does not recognise; write a value that mixes literal text with a template as a whole template or a secret reference.
