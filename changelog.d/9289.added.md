- **The dashboard's live stream carries activity and config changes.** The web UI stream now sends each new transparency-log record as an `activity` event and each governance-log record as a `config` event, as they are written. An admin scoped to some backends gets the activity of those backends only and no config events; full admins get both; a gateway with no governance log sends no config events. A reconnect that sends its last event id resumes after that record with nothing repeated or skipped, a stream that falls behind catches up from the log files, and a stream whose key loses access ends at its next check.
