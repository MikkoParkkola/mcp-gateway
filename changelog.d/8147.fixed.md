Every package manager a stdio backend runs (npm, npx, bunx, yarn, pnpm) now gets its per-backend cache from one assignment. A data directory whose path is not valid UTF-8, holds a `..` component, or holds `${`, is assigned to no runner and the backend keeps its runner's default cache, instead of a mangled path the runner would create elsewhere. An operator's cache setting is recognised in exactly the spellings that runner reads. Yarn Berry's global cache is turned off so the yarn cache folder, the gateway's or the operator's, takes effect. A non-UTF-8 `MCP_GATEWAY_CONFIG_DIR` is now used rather than silently replaced by the default (MIK-8147, MIK-7990).
