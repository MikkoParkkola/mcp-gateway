- **Pending restart on the Gateway read.** The bundled UI's admin-only `GET /ui/api/gateway` now answers `pending_restart`: `null` while nothing waits for a restart, otherwise `{fields}` naming the settings that only a restart applies. A changed startup environment value shows as the one id `environment`, never by the variable's name. Each listed setting stays until the gateway restarts or the file (or the environment value) is put back; a `HOME` assigned beside a `~` env-file entry keeps `environment` listed until a restart.
