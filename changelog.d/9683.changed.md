- **One `--gateway` flag, or `MCP_GATEWAY_URL`, for every command that talks to a running gateway.** `api`, `audit lookup-email`, `dashboard-link`, `events dead-letters` and `stats` take the gateway's base URL as `--gateway URL`, or from the new `MCP_GATEWAY_URL` environment variable when the flag is absent; without either they use the address in `--config` as before. The old spellings `--url` and `-u` still work on these five commands but no longer show in help. `add --url` is a different flag, the backend's own address, and is unchanged. docs/CLI.md, "Where remote commands send their request", gives the order.
