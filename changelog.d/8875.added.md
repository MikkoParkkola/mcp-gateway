- The new web UI's shell now renders at every `/ui/...` link instead of sending you on to `/ui`: the sidebar lists Overview, To do, Servers, Tools, Activity, Costs, Access, Policies and Gateway as a route line, each page's Status, Actions and Settings tabs are in the address, and Back, Forward, reload and shared links land on the same page and tab. Pages not yet built say so and link to the classic page. The theme follows the system's light, dark and high-contrast settings, there is a skip link, and touch targets are at least 44 px. A command palette (Ctrl+K or ⌘K, or the top bar's search) finds any page, action or setting and opens it on its tab; nothing runs from it. On phones a menu button opens the pages. When the gateway asks for sign-in, the new UI shows a sign-in card at the same address: open the one-time link the terminal printed, enter the handoff code from another device, or paste an API key, which stays in the tab's memory only. `/ui` itself stays the classic page until the new UI replaces it.
