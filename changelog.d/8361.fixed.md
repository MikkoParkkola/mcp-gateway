- **On `/mcp/{name}`, a caller with no connected account can no longer tell a hidden tool from a missing one.** For a per-user backend the caller has no view of, a call to a tool its policy hides used to answer "unknown tool" at once, while a call to a missing tool got the account's connect answer; the difference showed which names exist. The hidden tool now gets the same connect answer as the missing one, and is still never sent to the backend. (MIK-8361)
  Affects: clients calling a per-user backend on `/mcp/{name}` before connecting its account.
  Operator action: none; see UPGRADING (MIK-8361).
