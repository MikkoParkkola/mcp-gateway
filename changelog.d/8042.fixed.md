- **A gateway edit to `gateway.yaml` can no longer be erased by another writer.** A
  running gateway's web UI and admin edits now load, edit, write and reload the file under
  one lock, so a change made by another process at the same moment is kept instead of
  silently overwritten. The lock is a hidden `.gateway.yaml.lock` file next to the config,
  kept there on purpose. CLI writes (`add`, `remove`, `setup`, `cap discover
  --write-config`) take the same lock for their write: one that meets another writer's
  lock says `Waiting for ...` and continues once it is free; if it stays held for 30
  seconds the command writes nothing and exits non-zero, asking you to retry.
