- **Two config writers can no longer erase each other's change.** Every writer of
  `gateway.yaml` (the CLI's `add`, `remove`, `setup`, `cap discover --write-config` and
  `init`, and a running gateway's web UI and admin edits) now loads, edits and writes
  under one lock, so a change made by another process at the same moment is kept instead of
  silently overwritten. The lock is a hidden `.gateway.yaml.lock` file next to the config,
  kept there on purpose. A CLI write that meets another writer's lock says
  `Waiting for ...` and continues once it is free; if it stays held for 30 seconds the
  command writes nothing and exits non-zero, asking you to retry.
