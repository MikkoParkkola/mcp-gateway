- **A bad collusion glob is named by its key path, not its text.** A `security.firewall.collusion` glob that does not parse (in `sources`, `non_egress`, or an `allowed_flows` entry's `source` or `egress`) refused the config with an error that quoted the pattern. The error now names only the key path and index, such as `security.firewall.collusion.sources[1] is not a valid glob`, as the firewall rule errors already do. (MIK-8932)
  Affects: every release with `security.firewall.collusion` enabled. Operator action: none; a config that loaded before still loads.
