- **Cost history survives a restart.** With cost governance built in, the gateway saves 30 days of spend per API key, per hour and per local day, to `spend-history.json` beside `costs.json`, in the same save, and reads it back at start whether or not governance is on. The 24 h, 7 d and 30 d windows in `/api/costs`, the dashboard and `gateway_cost_report` no longer start at zero after a restart; the time the gateway was down stays a gap. Spend from calls with no API key is kept in a series of its own, and past 512 keys the keys with the least spend are summed into one overflow, so totals stay exact. Per-tool breakdowns still start at zero after a restart.
