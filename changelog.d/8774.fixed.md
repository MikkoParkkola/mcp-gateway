- **Credential redaction keeps JSON text over 1 MiB parseable.** A tool answer's JSON text over 1 MiB that held a credential, such as a large search page with a connection string in one entry, used to be redacted from the credential to the next space, so the rest of the answer was lost and a client could no longer parse it or read its row count. It is now redacted inside the JSON strings the credential covers, as smaller texts are: keys, numbers and the rest of the document arrive as sent, and a credential-named member's value is redacted as under 1 MiB. The text is checked with the same parser rules as before, but the parsed document, whose size set the 1 MiB limit, is never built. (MIK-8774)
