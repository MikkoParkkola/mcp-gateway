- **A grant subject that names no one cannot exist.** `GrantSubject::new` is the one constructor and returns `Result<_, EmptyIdentity>`, refusing an empty authority or subject; `GrantSubject::checked` is removed, the fields are private behind read-only accessors, and every deserialization goes through the same check, wherever the subject is nested. A grants file with a rule whose subject or owner names no one is refused at load, naming the file and each rule; `mcp-gateway upgrade` removes such rows (they granted nothing), backing the file up first. (MIK-9192)
  Affects: grants files with an empty subject or owner; library users who built `GrantSubject` with a struct literal or read its fields directly.
  Operator action: run `mcp-gateway upgrade` if startup reports a grant row naming no one.
