- `gateway_search_tools`, Code Mode search and `gateway_list_tools` now fill a backend's tool cache in the background when it was never filled, so a backend left out of a non-empty `meta_mcp.warm_start`, or one whose warm-start gave up, becomes searchable instead of staying invisible. The first search returns nothing for that backend and later ones match. A backend that is down gets one `tools/list` per fill cooldown, not one per search ([@terafin](https://github.com/terafin), [#3036](https://github.com/MikkoParkkola/mcp-gateway/pull/3036)).
