- **+ New Capability on the classic dashboard creates the capability.** It used to send a field the server ignored, so the server answered with its template, wrote nothing, and the page opened a capability that did not exist. The page now starts from the server's own template, named for the file you chose, and reports any answer other than "created" with the server's message. The name you type is lowercased and every character other than a letter, digit or `_` becomes `_` (a capability name allows nothing else, so the old example `my-tools` could never be created; the prompt now suggests `my_tools`); a name with no letter or digit left is refused before anything is sent. The UI write routes for capabilities, servers (add, edit, preview), OpenAPI import, sign-in confirm and the control plane now refuse a request body with a field they do not know instead of ignoring it; a client that sent extra fields gets a 4xx, and nothing is written. The answer names the field, except on the sign-in confirm, which keeps its own 400 for any body it cannot read.
