- **+ New Capability on the classic dashboard creates the capability.** It used to send a field the server ignored, so the server answered with its template, wrote nothing, and the page opened a capability that did not exist. The page now starts from the server's own template, named for the file you chose, and reports any answer other than "created" with the server's message. The UI write routes for capabilities, servers (add, edit, preview), OpenAPI import, sign-in confirm and the control plane now refuse a request body with a field they do not know instead of ignoring it; a client that sent extra fields gets a 4xx naming the field, and nothing is written.
