- **A crafted URL can no longer crash the gateway through `url`'s origin check.** The gateway compares URL origins on input it does not control: the target of a redirect during a remote OIDC fetch, and the endpoint a remote A2A agent card advertises. With `url` 2.5.8, a URL made of thousands of nested `blob:` prefixes overflowed the stack during that comparison and aborted the process (RUSTSEC-2026-0592). `url` is now 2.5.9, which reads the inner origin of a `blob:` URL only for `http`, `https` or `file`, so nested `blob:` prefixes can no longer recurse; any other inner URL gets an opaque origin, so such a URL is refused as a different origin. (#5228)
  Affects: 3.5.2 and earlier, and the 4.0.0 pre-releases. Operator action: none; upgrade.
