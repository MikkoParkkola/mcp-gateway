- **An API key in a JSON member is redacted.** A tool answer such as `{"api_key": "<key>"}` used to be delivered unredacted. The generic API-key rule needs the name, the separator and the quoted value in one string, and a parsed JSON member keeps its key and its value apart. The redactor now pairs a member's key with its value. When the key is `api_key`, `apikey` or `secret_key` (any case, `-` or `_` as the separator, alone or ending a longer name such as `x_api_key`) and the whole value is 20 or more characters of `A-Z a-z 0-9 + / =`, the value is replaced and reported as one finding. This applies to parsed JSON and to JSON carried as text, where escaped spellings of the name count too. Values the caller exempts are kept. (MIK-8756)
