- **The classic web UI is easier to read and to use without a mouse.** Primary and danger buttons, the active Add Server mode and the red status badges now meet the WCAG AA contrast ratio of 4.5:1; white on the accent blue was 2.53:1. Every form control has an accessible name, so a screen reader announces the Transport choice, the tools filter, the import URL and the environment-variable rows. The Control Plane tables, which scroll sideways on a phone, now take keyboard focus and can be scrolled with the arrow keys. (MIK-9009)
