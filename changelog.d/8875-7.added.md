- A page in the new web UI that fails now says why: the gateway could not be reached, it answered with an error (with the HTTP code), its answer could not be read, the item was not found, or the page itself failed. A fault in the page's own code no longer reads as an unreachable gateway. The page's last data stays visible, muted, under the message, with the time it is from, and a Retry button runs the page again. (MIK-8875)
