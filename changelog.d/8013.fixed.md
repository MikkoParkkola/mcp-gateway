- **A writer beside the config no longer costs the config watcher CPU.** Every write in the
  config's directory, such as a profiler's output or any other file, woke the watcher, which then
  re-resolved the config's whole link chain. Now only an event on the config file, a link on its
  chain, or a watched directory itself does. Edits, atomic renames, `ConfigMap` updates and
  release-link retargets reload as before, and a chain that cannot be resolved still wakes on
  every event and retries every 2 seconds. (MIK-8013)
