On a host clock set before 1970, the gateway no longer loses or wrongly ends work. A dashboard session is refused but kept (the browser keeps its cookie), and a sign-in link is refused without being used up. Task expiry pauses instead of deleting what it cannot date. An input round waits for the clock instead of being abandoned or left stuck. Budget spend restored at start-up still counts once the clock is right. (MIK-8202)
