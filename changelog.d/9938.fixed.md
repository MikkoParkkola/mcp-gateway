- **A refusal the gateway decides is recorded and counted as a refusal.** A call the spend budget
  or a response gate (the contract gate, anomaly screening, context integrity) refused was
  recorded `error`, or `tool_error` when the answer reached the caller as a tool result flagged
  `isError`, while its delivery record said refused. Its invocation record now says `denied`,
  with the refusing check's code (`-32600` for an answer withheld as a tool result), on `/mcp`
  and on the direct route. The web UI counts it as a block instead of an error, and
  `mcp_authz_denials_total` counts it. What the caller receives is unchanged. A backend's own
  error keeps its class. See `docs/UPGRADING-4.0.md` item 43.
