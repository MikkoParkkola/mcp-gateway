- **Secret saves wait for each other only as long as the caller allows.** A save of secrets through the gateway waits for another save's vault lock only until the caller's own deadline, then refuses with nothing written. The vault lock file, `<home>/.mcp-gateway-secrets.lock`, is accepted only when it belongs to the user running the gateway, with no exception for root. A rolled-back save deletes only its own new entries, and an entry whose removal fails stays in the unused listing, now shown with when it was written. (MIK-8908)
