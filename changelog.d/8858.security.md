- **Sign-in links and provider error text stay out of the log.** The authorization link a login logs now keeps only the provider's host and path, never its `state`, PKCE challenge or other query values. A provider's `error_description` on a refused sign-in is neither logged nor carried in the login's error; only its RFC 6749 error code is. (MIK-8858)
  Affects: every OAuth backend login.
  Operator action: none.
