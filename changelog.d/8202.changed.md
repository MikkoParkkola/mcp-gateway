- **Library types change for a host clock that reads before 1970.** `ToolInvocationAudit.timestamp` (the agent tool audit) is now `Option<String>` and a new `clock_invalid` flag is set; the audit JSON reads `"timestamp": null, "clock_invalid": true` only on such a host and is unchanged otherwise. `TokenInfo::from_response` is replaced by `TokenInfo::from_response_at(.., now)`, which dates a token from the clock reading its request was checked against. `TokenStore::live_jti(&self, jti, now: u64)` and `TemporaryToken::is_expired(now)` judge a key-server token on a clock reading the caller supplies, so one access check judges every credential on one reading; an implementor of `TokenStore` must judge on that `now` and not read the clock. Affects 4.0.0 pre-releases only (MIK-8202).
