- **A config reload is skipped while a config write is left unsettled.** A reload from the file watcher, the env poll or an admin request no longer loads `gateway.yaml` while an abandoned config-write file or a retired config-write manifest sits beside it, or while the gateway cannot tell whether one is there. That attempt is skipped and logged with its reason, the running config stays, and the next reload of any kind tries again. The check runs before any pending journal is recovered, so a skipped reload leaves `gateway.yaml` and the journal as they were.
  Affects: 4.0.0 pre-releases. Operator action: none unless the log reports such a skip. Then act on the reason it gives: for an abandoned write file, settle it or move it aside; for a retired manifest, move it aside by hand (it is kept as evidence) or run a build that reads it; if the check could not run, restore read access to the config's directory.
