- **A config reload waits while a config write is left unsettled.** The file watcher, the env poll and an admin-requested reload no longer load a new `gateway.yaml` while an abandoned config-write file or a retired config-write manifest sits beside it, or while the gateway cannot tell whether one is there. The running config stays, the skip is logged with its reason, and the next change retries. The check runs before any pending journal is recovered, so a skipped reload writes nothing.
  Affects: 4.0.0 pre-releases. Operator action: none; if the log reports such a skip, settle or move the named file aside.
