- **Less CPU per tool call, and per tool listing.** With no transparency log, a tool call no longer opens a grant-decision slot, and a slot that decided nothing no longer spawns a flush task. Request telemetry labels each request without copying its strings. A `tools/list` reuses each tool's trust-card reference while the tool is unchanged instead of recomputing it every time. (#3182)
- **Grant-decision records name the authority.** A decision record's `who` now carries the grant subject's authority as well as the subject. (#3182)
- **The request-id recovery read is bounded.** When an audit write fails after dispatch, the gateway reads the replaced answer to recover its request id. That read is now capped at 16 MiB; past the cap, the refusal carries a null id. (#3182)
