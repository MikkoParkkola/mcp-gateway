- **Per-caller tool visibility no longer copies capability definitions to decide or count.** 4.0's per-caller visibility checks each capability on `initialize` and `tools/list`. Each check cloned the full definition, and each listing cloned every capability's tool, schemas included, only to read its name. Under load that raised `tools/call` p99 latency. The checks now read definitions in place and count by name. (#2110)
