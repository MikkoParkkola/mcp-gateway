- **Only the capability loader can mark a definition pinned.** A program built on the crate could
  set `ProvidersConfig::integrity` to `Verified` on a definition it built, so a `cli` or `mcp`
  process provider ran without the `sha256:` pin check. `process` and `integrity` are now
  crate-private, read through `process()` and `integrity()`. Replacing a definition through
  `register_capability` now drops its cached answers, so a replacement cannot be served the
  original's result. See UPGRADING-4.0 item 144. (MIK-7814)
  Affects: no released version. Operator action: none; an embedder that read the fields calls the getters.
