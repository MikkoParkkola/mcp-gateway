- **A server turned off in the config stays listed.** A server written with `enabled: false` no longer disappears from `/ui/api/status` and the web UI. The full status view lists it after the running servers, by name, with `running: false`, `state: "off"`, its configured transport, no tools, its kept call counts, and `null` for the breaker and live counters it does not have. Servers › Status shows such servers in a block of their own, and the classic page draws "-" for the missing values. `server_count` counts them; `circuit_breakers` and the counts-only view count running servers only.
