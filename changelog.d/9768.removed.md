- **`asana` is no longer in the server registry.** Its endpoint, `https://mcp.asana.com/sse`, was shut down by Asana on 5 August 2026 and answers HTTP 410, so `mcp-gateway add asana` wrote a backend that could not connect. Asana's replacement, `https://mcp.asana.com/v2/mcp`, does not offer dynamic client registration, and `add` writes no OAuth client ID, so the entry cannot simply be repointed. To use it, add it by URL with an OAuth client you register with Asana: `mcp-gateway add --url https://mcp.asana.com/v2/mcp asana`, then set `oauth.client_id`, `oauth.client_secret` and an `oauth.callback_port` matching the app's Redirect URL. A backend already pointing at `/sse` is not migrated; repoint it the same way. Legacy SSE servers you add yourself are unaffected.
