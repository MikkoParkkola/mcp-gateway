- **A backend added while the events startup check runs keeps its subscriptions.** At startup the events hub withdraws the subscriptions of backends removed while the gateway was down. A config reload that added a backend in the middle of that check could have its stored subscriptions withdrawn although the backend was already registered. A registration now waits for the check to finish, so a backend registered before the check keeps its subscriptions. Affects 4.0.0 pre-releases only (MIK-7897).
