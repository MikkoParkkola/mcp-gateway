- **A tool marked high-risk in any letter case now ranks as unsafe too.** Tool search
  ranking read a catalogue entry's `risk_level` (or `risk`) label two ways: the risk
  signal ignored case and treated `blocked` as high risk, but the safety signal
  matched only lower-case `high`, `critical` and `unsafe`. A tool labelled `HIGH`,
  `Critical`, `UNSAFE` or `blocked` lost its risk score but kept a full safety score.
  Both signals now read the label the same way, so such tools rank lower on safety as
  well. (MIK-8549)
  Affects: tool search ranking for entries whose risk label is not lower case, or is `blocked`.
  Operator action: none.
