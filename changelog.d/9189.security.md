- **The web UI's live status stream follows the caller's backend scope.** A key scoped to some backends, admin or not, got status counts across every backend on `/ui/api/stream`, its event ids moved with changes outside its scope, and a reload that narrowed a plain key's backend list left its stream open under the old scope. The stream now counts only the caller's backends and never sends a scoped caller the full view; a scoped connection's status ids count the updates it was sent; and a reload that changes the key's backend list closes the stream, so the browser reconnects under the new scope. Reordering or repeating the same backends keeps it open. See UPGRADING. (MIK-9189)
  Affects: 4.0.0 pre-release builds, where a backend-scoped key or identity watching the web UI's live status saw every backend's counts. Operator action: none.
