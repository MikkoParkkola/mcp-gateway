- **A cancelled call stops on a legacy HTTP backend.** When a client cancelled a call, or the gateway
  gave up on it, a backend on the 2025 streamable-HTTP protocol kept running it, because nothing told
  it to stop. The gateway now sends that backend one `notifications/cancelled` naming the id the
  backend received, on the same session. An answered call and `initialize` are never cancelled. A
  2026 backend needs no message: closing the request's stream already cancels it.
