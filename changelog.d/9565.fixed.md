- **The web UI's server status tells the truth about a server its runtime settings keep from starting.** A server whose runtime profile asks for a host mount, full network access, privileged mode or guarded environment names is refused at every start, and nothing in the product can approve those settings. Its status used to say its last start had failed and that the next call would try again. It now reads Refused, names the settings in plain words, and says the server will not start until they change.
