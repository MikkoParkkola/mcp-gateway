- **CLI config writes no longer drop `gateway.yaml` comments silently.** `add`, `remove`,
  `setup wizard` and `cap discover --write-config` keep comments when the change can be written
  as a text edit, one backend at a time, and the file is written once. When it cannot (a
  flow-style mapping, a comment inside a changed value, or a change outside `backends`), the
  command writes nothing, exits non-zero, and names the lines of the comments a rewrite would
  drop. `--force` names the same lines, then rewrites the file without them. The web UI's
  refusal message now points to `--force` instead of `add` / `remove`.
