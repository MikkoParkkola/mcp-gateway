- **Setting `MCP_GATEWAY_CAPABILITIES` no longer breaks config loading.** The tool subcommands read it as their capabilities directory, but the config env overlay also read it as the `capabilities` key, so `serve`, `validate` and every other config load failed. The overlay now skips the eleven `MCP_GATEWAY_*` names that CLI flags own, matching whole names only. `serve` and `validate` keep the directories in the config; nested overrides such as `MCP_GATEWAY_SERVER__PORT` and `MCP_GATEWAY_CAPABILITIES__NAME` apply as before. (MIK-8367)
