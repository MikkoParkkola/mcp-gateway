- **`dashboard-link` and `events dead-letters` never print the admin token.** Both commands masked only the gateway's error reason before. The token could still reach the terminal through the HTTP status text (a token equal to `404`, `OK` or `Found`), the success JSON or link, the line prefix or closing note, or a config-load error that quotes the config. Every line both commands print once a token is set now passes the shared redactor, with a fixed sentence when masking cannot remove the token. An answer whose redaction would merge two JSON keys is refused, as `mcp-gateway api` already did.
  Affects: anyone running these two commands against a gateway that echoes the token, or with a token short enough to appear in ordinary output. Operator action: none; rotate the token if earlier output was shared.
