- The web UI can sign an OAuth backend in again. An admin with a dashboard session starts the sign-in from the backend's row, opens the provider's link, and confirms the result; the token is saved only on that confirm, and a cancel works at any point. Each backend row now shows whether it needs a sign-in (`needs_sign_in`), its sign-in status and expiry, and a sign-in in progress. One sign-in runs per backend at a time, shared with the CLI and startup logins. (MIK-8858)
