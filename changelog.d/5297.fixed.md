- **An OpenAPI import never replaces an existing capability file.** Importing a document whose operation formats to a capability name already on disk (from another API, or two operations of one document whose names differ only in case or punctuation) silently replaced that file, so a tool could start calling a different API. Now the file is kept byte for byte, that tool is reported with what to do (remove the capability or rename the operation), and the other tools are still written. The web UI import checks every capability directory the gateway loads and answers 409 when every selected tool was refused; `cap import` exits 1 when any tool was not written. See UPGRADING.
  Affects: anyone who imports OpenAPI documents. Operator action: to refresh an imported API, remove its capabilities and import again.
