- **The config revision now covers capability files.** The config revision a decision record and its receipt carry (`config_revision`) is now computed over the capability files the gateway serves as well as gateway.yaml, its env files and grants: each served capability file's path and the digest of the bytes the gateway parsed. Editing, adding or removing a capability file gives a new id, and the same files give the same id again. Until the startup scan has loaded the catalogue the id says so, and a scan or reload that could not read a configured directory or file is marked partial. A receipt whose revision does not cover the capability files says "capabilities not included", or "capabilities included from the directories that could be read" for a partial one; a record written before this change reads as not included. The startup scan reports ready only once its revision has reached the running configuration, and it still registers capability webhook routes before that.
