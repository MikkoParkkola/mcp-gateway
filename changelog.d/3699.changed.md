- **With auth on, the audit log is on by default.** An authenticated config no longer needs
  `security.transparency_log.enabled: true`; with no section the log is on at its default path,
  and a section that sets only `path` turns it on at that path. Writing `enabled: false` with auth on still fails the load,
  and with auth off nothing changes. Commands that rewrite the config do not add the line.
  Library code: `security.transparency_log.enabled` is now `Option<bool>`; set it with
  `Some(true)` and read it with `is_enabled(auth_enabled)`. (MIK-8044)
  Affects: 4.0.0 pre-releases.
  Operator action: none.
