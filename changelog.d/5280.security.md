- **A signed call refused for its envelope is now in the audit log.** With message signing on, a `tools/call` whose id the answer cannot carry, or whose tool name changes when it is sanitized, was refused on `/mcp` and on stdio without a record. It now leaves one record, outcome `denied` and decision kind `syntax`, and its answer is unchanged. The one exception: under a fail-closed audit log that cannot be written, it answers that the log is unavailable (HTTP 503, `-32005`), as every other signing refusal already does. See UPGRADING.
  Affects: 4.0.0 pre-release builds with message signing on. Operator action: none.
