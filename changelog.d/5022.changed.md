- **The library's tests can be built in five parts.** Each test module now carries a part tag, and a build script turns parts on from `MCP_GATEWAY_TEST_PART`, so the library's test binary can be compiled as five smaller builds instead of one rustc of about 19 GB. Nothing selects a part yet: with the variable unset, every part compiles, so `cargo test`, `cargo build` and the release build compile exactly what they did before.
