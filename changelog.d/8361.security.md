- **A tool the caller may not see answers exactly as a tool that does not exist.** A call to a tool hidden from the caller (by its tool policy or key scope, its routing profile, an invalid input schema, a description that failed the poisoning check, or, for a capability, the admin rule or a missing grant) used to get a refusal naming why, which let a caller probe which tools exist. It now gets the answer a missing name gets, on `/mcp`, stdio and `/mcp/{name}`, and is never sent to the backend. One exception is kept: an exact replay of an idempotency key gets the step's current refusal, since its caller held the step before; a key reused with other arguments answers as for a missing step. (MIK-8361)
  Affects: clients and operators who read refusal reasons from the client's answer.
  Operator action: read refusal reasons in the audit log; see UPGRADING (MIK-8361).
