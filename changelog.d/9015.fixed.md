- **The registry search in Add Server works from the keyboard.** It now behaves as an accessible combobox. The arrow keys move through the results, which stay in view as the list scrolls; Enter picks one, and Escape or Tab closes the list. The box, the list and the active result carry combobox and listbox roles for assistive technology. Editing the search text after a pick now clears the pick, so Add no longer adds an entry the box has stopped naming. (MIK-9015)
