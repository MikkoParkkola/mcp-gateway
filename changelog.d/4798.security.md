- **Preview install: a fetched package that is not plain registry content is refused before anything runs.** The checks sit in `src/preview_sandbox/install.rs` and are not yet reached by a route. An npm lock is refused when any entry, the root included, is a link or is not a registry tarball, or when a declared dependency is a git, file, URL, leading-dot or archive-suffixed spec, or an edge no entry satisfies. The npm run file must stay inside its package directory, which must stay under the install root; the uv console script comes from the package's own entry points (exact name first, a path-like name refused), never from a listing of `bin/`; metadata files must be regular files of at most 1 MiB. (MIK-8905)
