- **A config save refuses rather than overwrite another account's file or another process's change.** On Linux and macOS the shared writer behind every config save now looks at the file before replacing it. A file that belongs to another user is saved only by root (`foreign-owner`). A file that another process replaces or changes during the save is left as that process wrote it (`target-changed`). On macOS, a file the gateway cannot read to check its access list is not replaced (`acl-not-kept`). Each refusal says what to do and that nothing was written. The admin UI's backend update answers it with a 409, and `mcp-gateway remove` exits non-zero. A refused web UI save also no longer puts the old file back over the other process's newer one.
  Affects: 4.0.0 pre-releases. Operator action: none, unless a save now reports `foreign-owner`; then run the gateway as the file's owner or hand the file to the gateway's user, as the message says.
