- A backend can list the only tools it offers: `backends.<name>.allowed_tools`, with the grammar of an API key's `allowed_tools`. A tool outside it is left out of every tool list and refused by name, including one the server adds later. The web UI's add and edit API (`POST`/`PATCH /ui/api/backends`) take the list, and the admin tools list marks each tool selected or not. (MIK-8838)
