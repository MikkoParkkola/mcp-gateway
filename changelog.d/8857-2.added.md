- A running server whose recent calls are far slower than its own usual now reads `slow` in the web UI's server list: the p95 of its last 100 answered calls is over three times its usual p95 and at least 50 ms. The usual is learned from the server's own traffic since the gateway started, so a server with fewer than 500 answered calls since then never reads `slow`, and a slowdown that lasts becomes the new usual (a tenfold one shows for about 2,000 calls). `slow` never hides a worse state: paused, unhealthy, refused and sign-in states still win. (MIK-8857)
