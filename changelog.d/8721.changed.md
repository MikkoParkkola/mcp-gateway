- **`gateway_list_servers` reports `tools_count: null`, not `0`, for a backend whose tools are not known to the caller yet.** `tools_known: false` already marked such a row, but agents read the bare `0` as "this backend serves no tools" and gave up on working backends. The count is now null until the backend's tools are known for that caller (not enumerated yet, or not visible to it), and a number, possibly 0, once they are. The tool description says so and points at `gateway_list_tools(server)`. Reported and fixed by terafin in #4040, ported to the 4.0.0 line. (MIK-8721)
