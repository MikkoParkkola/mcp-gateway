- **The web UI can create an API key.** `POST /ui/api/keys` (admin only) takes the key's name, backends, tool lists, admin flag, rate limit, an optional expiry and the `gateway.yaml` revision it was listed against. The gateway generates the secret, writes only its digest to `gateway.yaml`, and returns the secret once, with `Cache-Control: no-store`. The write is recorded in the audit log before the file changes, naming who created which key; if that record cannot be written, nothing is. `GET /ui/api/keys` now answers `{revision, keys}`, so a create can name the revision it read.
