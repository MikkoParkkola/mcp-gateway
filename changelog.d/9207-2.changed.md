- **`VerifiedIdentity`'s fields are private.** Library code reads `key_server::oidc::VerifiedIdentity` only through its accessors (`subject()`, `email()`, `name()`, `groups()`, `issuer()`); code outside the crate can no longer build one, copy one with a field changed, or change a field of one. The gateway's own verified sources are unchanged. (MIK-9207)
