- **Contributors: one build for all of a change's mutation proofs.** A scratch commit can wrap each mutated expression in `mutant!("ID", mutated, original)`; one build with `--cfg mutants` then carries every mutant, and each test process switches on at most one, named by `MCP_GATEWAY_MUTANT`. A normal build expands the macro to `original` alone (no runtime check, no environment read), and a test scan of every tracked `.rs` file refuses any `mutant!` call outside `src/mutant.rs`, so no mutant site can be merged. No change for users of the gateway. (MIK-9381)
