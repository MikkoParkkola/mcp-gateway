- **Add a server with only the tools you tick.** The classic web UI's Add Server form has a **Preview tools** button. It shows what the preview will contact and what it withholds, and after **Start preview** it lists the server's tools with a checkbox each. Read tools start ticked; write tools, and names the gateway will not call, start unticked. **Add Server** then saves only the ticked tools as the backend's `allowed_tools`, so a tool the server adds later stays off until you tick it. Add is refused while nothing is ticked, when the listing was cut short, or when the form has changed since the preview. Without a preview, Add works as before and offers every tool. (MIK-8838)
