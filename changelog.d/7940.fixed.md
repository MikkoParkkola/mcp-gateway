- A capability whose OAuth login expires is now announced with `tools/list_changed` when it stops being listed, without a reload, and the file watcher's reload announces login and key edits as the explicit reload does. An owner-scoped event, such as a task's final status after the task record expired, is no longer refused and its subscription revoked by the delivery worker. Affects 4.0.0 pre-releases only (MIK-7940).
