- **The web UI can list the decisions an admin has open.** `GET /ui/api/decisions` (admin only) lists access requests (a subject and proven agent refused a personal capability for want of a grant, newer than any decision on it and not covered by a live grant) and changed capabilities (a capability file whose bytes no longer match their pin), with an opaque id, what each waits on and display-safe fields only: names that pass the backend-name rule or a keyed label, an issuer as its host, a changed file as counts, mapped types and its inferred risk class. The list is held in memory, kept current from the transparency log and a startup replay of it, and answered without a scan; while a source is still being read it answers 503 naming that source.
