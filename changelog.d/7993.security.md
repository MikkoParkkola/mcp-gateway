- **A task result read later no longer counts the gateway's own text as the backend's.** With relay detection on, `tasks/get` now leaves out of its relay receipt the members the gateway wrote into the stored result (`trace_id`, cost advice, security findings, provenance, contract annotations), on chains and playbooks too. A backend member of the same name stays in the receipt. Task rows gain an optional `gatewayWrites` member; rows without it read as before. (MIK-7993)
  Affects: the 4.0.0 pre-releases, with relay detection on, for task results read with `tasks/get`. Operator action: none.
