- **`mcp-gateway add filesystem`, `add memory` and `add sequential-thinking` now write current, non-deprecated pins.** The registry pinned `@modelcontextprotocol/server-filesystem`, `-memory` and `-sequential-thinking` at the date-based `2026.8.31`, which npm now marks deprecated ("Date-based versions are no longer published. This package has resumed semantic versioning at 1.0.0"). The three entries now pin `1.0.0`, upstream's final legacy release. Differences you can see: `sequential-thinking` now reports its tool as not read-only and not idempotent, so a read-only role no longer lists it; `memory` rejects a relation that names an entity that does not exist, and with no `MEMORY_FILE_PATH` set an entry added on the new pin starts an empty graph in its own `npx` cache; `filesystem` fails visibly when started with no directories and no client roots. Existing configs keep their pins. Operator action: to move an existing entry, re-add it or edit the version in the config; set an absolute `MEMORY_FILE_PATH` first if the memory graph matters.
