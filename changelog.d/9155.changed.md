- **The in-place config editor can now remove one API key entry from `auth.api_keys`.** This is the edit the web UI's key revoke makes. The entry's lines are removed with any comments on them, and those comments are reported back by original line number, never by their text. If it was the only key, the `api_keys:` line goes too, and so does an `auth:` block it leaves empty. Every other line is kept byte for byte. An entry the editor cannot remove safely (one with an anchor, tag or alias, or a list written inline) is refused. The refusal says how to revoke the key by hand: set its `expires_at` to now and reload, or delete the named lines and reload. Removing any other list element is still refused.
  Affects: 4.0.0 pre-release builds; 3.x had no in-place editor. Operator action: none.
