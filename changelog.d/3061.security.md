- **A disabled accounts block with an adapter checks every key reference before reading any.** Such a block's `file:` keys are read at load, and a malformed sibling key was refused only later, when the adapter was built. The load is now refused first, naming the key, and no secret file is opened. (#3061)
  Affects: the 4.0.0 pre-releases. Operator action: none; such a config was already refused when the adapter was built.
