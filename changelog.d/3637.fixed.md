- **Linear issue writes show the description Linear stored.** `linear_update_issue` and `linear_create_issue` now ask Linear for the issue's description in their answer, so a caller can compare the text it sent with what was saved. Before, the answer left the description out, so a write that did not apply looked the same as one that did. Two description writes to one issue in one session are covered by a regression test. The original report of a dropped second write did not reproduce on this release. (MIK-7507)
