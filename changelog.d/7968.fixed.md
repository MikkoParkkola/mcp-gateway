- **Web UI backend edits keep the comments in `gateway.yaml`.** An edit now changes only the
  keys that changed, so the entry's comments, inline comments and every other line stay. An edit
  that cannot be written as a text change (a flow-style mapping, or a comment inside the changed
  value) is refused with `409` naming the comments a full rewrite would drop, and the file is left
  untouched. The CLI keeps its full-rewrite fallback.
