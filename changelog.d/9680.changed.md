- **`dashboard-link`, `events dead-letters` and `audit lookup-email` exit with distinct codes and say what to do next.** They now exit with the same codes as `api`: 0 ok, 1 local failure, 2 usage, 3 auth refused, 4 not found, 5 network, 6 gateway error, and 8 when a replay may have run but its answer was lost. Before, every failure exited 1. Errors print as `error: <what went wrong>`, then what to do next, without the command-name prefix. They pass the same credential gate as `api`: the token never prints, nor the email or page token `audit lookup-email` read from stdin. `api`'s remedy for a missing or refused credential now names `MCP_GATEWAY_TOKEN` instead of a `login` command that does not exist yet. The new docs/CLI.md lists the exit codes, the output rules and which commands have a JSON form.
  Affects: scripts that ran one of the three commands and tested for exit 1. Operator action: test for a nonzero exit, or for the code you care about.
