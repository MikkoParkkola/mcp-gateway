- **A task input round near the record size limit is judged by the answer it will really store.**
  The check that a round leaves room for its shortest answer now measures the record as the answer
  is actually written, so a round is no longer refused when that answer would fit, nor taken when
  it would not. (MIK-7661)
  Affects: 4.0.0 pre-releases. Operator action: none.
