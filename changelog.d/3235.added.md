- **Signed Helm chart on each stable release.** The tag run publishes the chart to `oci://ghcr.io/mikkoparkkola/charts/mcp-gateway`, pinned to the signed image digest and cosign-signed by the same workflow identity as the image (`.github/workflows/ci.yml@refs/tags/<tag>`). A published chart version is never replaced, and prerelease tags publish no chart. (#3235, MIK-7952)
