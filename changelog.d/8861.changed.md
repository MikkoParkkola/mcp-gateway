- **`security.sanitize_input` and `security.ssrf_protection` apply on reload.** The next request after a reload uses the new values, over HTTP, stdio, task resumes and the UI's OpenAPI import and server preview; a request already in flight keeps the values it started with. A reload that changes only these two no longer reports `security` as needing a restart, and one that changes only `idempotency`, `events` or a restart-only `server` field is now reported. (MIK-8861)
