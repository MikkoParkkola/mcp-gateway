- **The cost views show what each call was charged.** `/api/costs`, the dashboard's cost view and `gateway_cost_report` reported $0 for every API key, session and the total, because each call was recorded with no price. A call is now recorded at the cost the budget limits charge for it (the tool's `tool_costs` entry, else `default_cost`), so these views and the daily limits count the same dollars. With cost governance off nothing is priced and calls still count at $0. Spend recorded before the upgrade is not restated.
