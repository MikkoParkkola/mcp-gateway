- **The cost views show what each call was charged.** `/api/costs`, the dashboard's cost view and `gateway_cost_report` reported $0 for every API key, session and the total, because each call was recorded with no price. A call is now recorded at the cost the budget limits charge for it (the tool's `tool_costs` entry, else `default_cost`), so these views and the daily limits count the same dollars. A gateway started with cost governance off prices nothing, so its calls still count at $0; turning governance off by a live reload keeps the running prices until a restart, as the budget limits already did. Spend recorded before the upgrade is not restated.
