- **The docs now say how much of a large tool answer context integrity checks.** Above a 64 KiB threshold it classifies only the start and end of an answer, under every preset, `team_shared` and `hardened` included, so content placed in the middle cannot by itself get the answer withheld. The security posture table and its known limits, the OWASP ASI06 row and the context integrity page each state this. Before, the posture table and the ASI06 row read as a check of the whole answer, and the context integrity page mentioned a sample without its size or what it leaves out. Behaviour is unchanged. (#5232)
  Affects: 3.5.2 and earlier, and the 4.0.0 pre-releases. Operator action: if an untrusted backend can return answers over 64 KiB, do not rely on context integrity alone to stop instructions or secrets placed in the middle of one.
