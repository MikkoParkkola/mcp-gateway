- **The docs now say how much of a large tool answer context integrity checks.** When the text of an answer is over 64 KiB, it classifies only the first and last 32 KiB. Content between them is never classified under any preset, `team_shared` and `hardened` included, so an instruction or a secret placed there does not by itself stop the answer. The security posture table, the OWASP ASI06 row and the context integrity page each state this; before, they read as a check of the whole answer. Behaviour is unchanged. (#5232)
  Affects: 3.5.2 and earlier, and the 4.0.0 pre-releases. Operator action: if an untrusted backend can return answers over 64 KiB, do not rely on context integrity alone to stop instructions or secrets placed in the middle of one.
