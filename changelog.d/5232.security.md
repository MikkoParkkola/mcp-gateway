- **The docs now say how much of a large tool answer context integrity checks.** Above 64 KiB, it classifies only the first and last 32 KiB of an answer, and the content between them is delivered unclassified under every preset, `team_shared` and `hardened` included. The security posture table, the OWASP ASI06 row and the context integrity page each state this; before, they read as a check of the whole answer. Behaviour is unchanged. (#5232)
  Affects: 3.5.2 and earlier, and the 4.0.0 pre-releases. Operator action: if an untrusted backend can return answers over 64 KiB, do not rely on context integrity alone to stop instructions or secrets placed in the middle of one.
