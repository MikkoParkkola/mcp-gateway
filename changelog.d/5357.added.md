- **The gateway's own health history for the web UI.** `GET /ui/api/gateway/health` (admin only) serves what the health store already records: added-latency p95 and gateway errors for the last complete hour against the hour before, the highest memory and session samples in the current half-hour, 16 half-hour points, and the uptime strip of six-hour blocks overlapping the last 7 days with each restart's downtime marked measured or estimated. It answers 503 when the process keeps no health history.
