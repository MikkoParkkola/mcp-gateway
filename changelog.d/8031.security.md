- With gateway authentication off and agent authentication on, each validated agent now owns its own tasks; before, every agent shared one task owner, so one agent could read, cancel or replay another's task and listen to its notifications. With agent authentication off, callers still share one pool, as before. (MIK-8031)
  Affects: the 4.0.0 pre-releases, in deployments with gateway authentication off and agent authentication on. Operator action: none; tasks an agent created before the upgrade stay in the shared pool until they expire.
