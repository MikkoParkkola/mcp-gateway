- **A stdio request makes one fewer large allocation and about 3.7 KB less.** Since MIK-8154's intake change, every stdio request boxed its dispatch inside the per-request visibility record, although the serve loop already boxes that dispatch. That box was a second heap copy of about 5 KB per request, a refused one included. The dispatch is now pinned in place instead. Measured on a refused signed `gateway_invoke` over stdio, run as the serve loop runs it: 18,505 bytes in 3 large allocations before, 14,793 bytes in 2 after. (MIK-8400)
  Affects: every stdio request, refused or admitted.
  Operator action: none.
