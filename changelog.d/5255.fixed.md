- **`setup export` writes a URL a client can reach.** In proxy mode the exported entry used
  `server.host` and `server.port` as written, so a wildcard bind (`0.0.0.0`, `::`) gave clients an
  address nobody can connect to, an IPv6 host came out unbracketed, and a TLS listener got
  `http://`. A wildcard bind now exports its family's loopback, IPv6 hosts are bracketed, and the
  scheme is `https` when the listener serves TLS. A declared `server.public_url` decides the URL;
  one no client can use (not http or https, an unspecified host, a user or password, a query or a
  fragment) stops the export with one error line before any file is touched. The command prints a
  note on stderr for each thing the entry cannot say by itself (loopback standing in for a
  wildcard, the CA and certificate name under TLS, a required client certificate), and its closing
  `Gateway endpoint:` line names the URL written. `--watch` prints the same notes after each
  regeneration and skips one whose URL is refused. (#5255)
