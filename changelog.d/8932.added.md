- **A firewall rule can be scoped to backends, API keys, and exceptions.** `security.firewall.rules[]` takes three optional keys: `servers` (globs over backend names), `keys` (API key names, matched exactly), and `except` (entries of `server`, `tool`, and `key`; a call that matches every field an entry sets is skipped). A rule without them applies to every call, as before. An empty `servers` or `keys` list, or an `except` entry with no field set, refuses the config at load. An answer that names no backend, such as a discovery listing or a notification, is judged as each registered backend's, so a rule scoped to any backend still covers it.
