- A legacy upstream peer can no longer hold more of the gateway's `resources/subscribe` subscriptions than the per-backend URI cap: a subscription the gateway cannot rule out stays counted until the backend is removed from or replaced in the config, or the gateway restarts. Updates for URIs nobody watches no longer take room from wanted ones. Affects 4.0.0 pre-releases only (MIK-7898).
- An upstream event listener no longer reads an unresolved protocol era as legacy, replaces a modern stream before its hourly cut while the old one keeps delivering, backs off listens that are never acknowledged, and re-handshakes a session whose stream open is answered 404. Affects 4.0.0 pre-releases only (MIK-7899, MIK-7898).
