- The web UI can preview a server before you add it: `POST /ui/api/previews` connects to an http(s) MCP server once, lists its tools with a read or write class, and disconnects. Nothing is saved, and none of the server's credentials are sent. A preview needs an admin token and a confirmation step, runs one at a time, and stops at 30 s, 4 MiB per response and 8 MiB in total. Command servers are refused until the preview sandbox lands. The OpenAPI import preview now shows the same preview block and a read or write class per tool. (MIK-8838)
