- **Firewall rules, credential redaction and the tool policy apply on reload.** A reload that edits `security.firewall.rules`, turns `security.firewall.credential_redaction` on or off, or changes `security.tool_policy` decides the next call over HTTP, `/mcp` and stdio. A request's checks use the config it arrived under; a response, task result or event is judged by the config in force when it is scanned. A reload that changes only these fields no longer reports `security` as needing a restart. The firewall's other settings still need one. (MIK-8861)
