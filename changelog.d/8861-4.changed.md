- **Firewall rules, credential redaction and the tool policy apply on reload.** A reload that edits `security.firewall.rules`, turns `security.firewall.credential_redaction` on or off, or changes `security.tool_policy` decides the next call over HTTP, `/mcp` and stdio. A request's checks use the config it arrived under. An answer to it is judged under that config and the one in force when the answer is scanned, and the stricter result stands: refused if either refuses, redacted if either redacts. A task result as it settles, a watch poll or an event has no request behind it, so it is judged by the config in force when it is scanned. A reload that changes only these fields no longer reports `security` as needing a restart. The firewall's other settings still need one. (MIK-8861)
