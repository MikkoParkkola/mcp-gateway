- **stdio refuses the methods MCP 2026-07-28 removed, as `/mcp` does.** A stdio client that
  declared the 2026-07-28 revision was still served `ping` and `logging/setLevel`, and got a
  different `Method not found` text for `resources/subscribe` and `resources/unsubscribe`. It
  now gets `-32601 method '<method>' was removed in MCP 2026-07-28` for all four, and for
  `notifications/roots/list_changed` when that carries an id. The same check also refuses a
  revision this build does not serve (`-32022`, with the list it could retry on) and a method
  whose client capability was not declared (`-32021`). A request that declares no revision, and
  any other notification, is answered exactly as before. A JSON-RPC batch item runs with modern
  serving off, so a modern item in a batch now gets `-32022` with an empty list. (MIK-8368)
  Affects: stdio clients that declare MCP 2026-07-28.
  Operator action: none.
