- **A destructive call refused for a caller the gateway cannot name is recorded as refused.** A task-augmented destructive call from a caller with no credential and no identity is answered `-32003` ("this destructive call cannot be confirmed for a caller this gateway cannot name"). Its delivery record used to say `delivered`; it now says `refused`, so refusal counts include these calls. Only HTTP reaches this answer: a stdio caller is always named by its session. Other confirmation answers keep the records they had. (MIK-9156)
