- **A host clock that reads before 1970 no longer produces 1969 or 0 stamps or guessed decisions.** The gateway's remaining clock reads now refuse (new tasks, chain receipts and links, signing, provenance, subscriptions, the grant snapshot at start, the control-plane grant view), wait for the clock (a task's input round and redemption, bounded by the task's ttl), or record the event undated (delivery records). Session idle deadlines are dated at the first readable reap. Affects 4.0.0 pre-releases only (MIK-8202). Events, OAuth and the key server follow the same rules: an expired backend token is never used, no token request or temporary token is issued, webhook signatures and deliveries are refused or held without counting an attempt, held subscriptions and dead letters are left as they are, events that cannot be dated are dropped and counted, and audit entries are written undated.
