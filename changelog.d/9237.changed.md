- `mcp-gateway doctor` counts unused secret entries with the same check as the Settings list: an entry named only by an env file the config lists, by a value in the process environment, by a capability file in the config's capability directories, or through a `file:` reference's link is no longer counted as unused. A reference inside a YAML comment now counts as naming its entry, as it does for the Settings list. Doctor now loads the config with its env files, so a config that does not load leaves the count out with a fixed reason. The row's hint says that a running gateway's Settings list, which also reads its live capability directories, can show fewer.
