- **A CLI write no longer recovers a pending config write unaudited.** When a gateway's audited config write fails and its rollback fails too, it leaves a replace journal beside `gateway.yaml`. A CLI command that writes the config used to recover that journal on taking the config lock, with no audit record. It now refuses, writes nothing and leaves the journal in place, and says to start or reload the gateway, which recovers it. A reload on a gateway with an audit log records the recovery there. (MIK-9291)
