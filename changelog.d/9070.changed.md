- **The public credential calls return a value that is wiped when dropped and never printed.** `MetaMcp::resolve_propagation_headers` and `MetaMcp::resolve_propagation_credential` now return the caller's minted headers as `identity_propagation::PropagatedHeaders` instead of a plain vector. The value is wiped when it is dropped, its `Debug` shows header names only, and the headers are read by borrowing; `.to_vec()` makes an explicit plain copy that is the caller's to wipe. Before, the library handed the credential out in a plain vector that was freed without being wiped.
