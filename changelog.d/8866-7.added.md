- The gateway keeps a seven-day record of its own health in `health.json` in its data directory, next to `counters.json`: per half-hour the added-latency distribution, the errors clients received by kind, and the largest resident memory and session count sampled; per six-hour block the time it ran, the time it was down and how many restarts it had. A restart after a clean stop records its downtime as measured; after a crash, as estimated from the last save. The file holds only numbers and fixed words, never anything a client sent. It is saved once at startup before anything is served, every five minutes and at shutdown; a failed save is logged and never stops the gateway from starting. A file that does not decode is set aside and the record starts again. (MIK-8866)
