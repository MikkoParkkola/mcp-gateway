- **The web UI can adopt a server it found in another app's config file as a disabled backend.** `POST /ui/api/discovery/adopt` (admin only) takes a find from `GET /ui/api/discovery` and the `gateway.yaml` revision it was listed against, never a command, URL or value. The server is read again from its client file and judged by the same rule as the listing; its literal env and header values go to the secret store and only their references to `gateway.yaml`, where the backend is added disabled, in place, with comments and layout kept. A change that cannot be made in place, a stale revision, a client entry changed since the listing, a name already in use and a value the store cannot hold are refused, and no answer or log line carries a value. (MIK-8859)
