- Config validation refuses a `capabilities.name` equal to a registry backend name, and CAP-003 refuses a capability `schema.input` that is a string, number, boolean or list, so the loader skips that capability. A missing, `null` or `{}` input schema still loads. `cap discover --write-config` skips a discovered server named like `capabilities.name` (the default export name, `gateway`) with a warning. See UPGRADING (MIK-8358).
