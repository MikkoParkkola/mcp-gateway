- **A response-firewall Block on a tool listing or a task result is now refused, never served.** The direct route (`/mcp/{name}` `tools/list`) logged a blocking verdict and served the list; `gateway_list_tools` and `gateway_search_tools` redacted a blocked list and served it as a success, and inspected it twice; task results passed no firewall at all. Each is now inspected once and a Block answers with the JSON-RPC -32600 refusal; a task settles on that refusal, so `tasks/get` never serves the result. A list with any blocking finding (by default, credential material in a tool description) is refused whole. (#2349, #2350, #2351)
