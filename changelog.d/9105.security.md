- **A backend can no longer echo a credential its `headers:` or `env:` configuration gave it back to the client.** A value written as an `env:`, `file:` or `keychain:` reference, and a variable substituted into a header (`Bearer ${TOKEN}`), is removed from everything that backend sends back, at any length, the same way an injected `secrets:` value is: each occurrence becomes `[redacted]`. An `env:` value written as nothing but `${VAR}` references is treated as a secret when it is 8 bytes or longer; a shorter one is left as it is and its field is named in one warning. A literal value, a template mixed with other text (`${HOME}/bin`) and a `:-default` the gateway fell back to are never redacted. The values stay redacted for as long as they are configured; one a reload removes stays redacted for the redaction grace. The README and `examples/minimal.yaml` now write the Tavily key as `env:TAVILY_API_KEY`. (MIK-9105)
  Affects: backends with credentials in `headers:` or `env:`. Operator action: none; to mark a short env value secret, write it as an `env:` reference.
