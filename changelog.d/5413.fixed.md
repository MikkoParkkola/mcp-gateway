- **A backend answer over the size limit is refused, not held whole.** An HTTP backend's answer,
  as a JSON body, an error body or an event stream, is now counted while it is read against the
  backend's `max_frame_bytes` (default 16 MiB, the same limit stdio frames have). One over it
  fails that call with `RESPONSE_TOO_LARGE` and `retry: false`, and the hint names the key to
  raise. Before, a 64 MiB answer took the gateway to about 1.4 GB of memory. An event stream is
  held to the limit per event, so long runs of small progress notes still pass. An oversized
  answer does not count against the backend's circuit breaker.
