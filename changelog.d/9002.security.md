- Security: the gateway's recovery hint, call prediction and trace id are now `_recovery`, `_predicted_next` and `_trace_id`, removed from a backend's answer on the way in, so a backend can no longer forge them; the plain names pass through as backend data. Stored task results are delivered without any gateway-only member their row does not record as the gateway's own write; a result stored before 4.0 that carried backend-planted gateway members is delivered without them and without its public signature; the internal receipt remains.
