- **`doctor` names hidden config settings.** `mcp-gateway doctor` adds a "Hidden settings" warning listing every key in your `gateway.yaml` that 4.0 leaves out of the configuration reference (tuning values the gateway now manages). Each value you set is still applied; nothing needs to change. `mcp-gateway init` no longer writes `meta_mcp.cache_ttl`, whose value equalled the default, so a new configuration shows no warning.
