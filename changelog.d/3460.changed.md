- **`doctor` lists advanced settings.** `mcp-gateway doctor` now shows an "Advanced settings" line naming each key in your `gateway.yaml` that 4.0 leaves out of the configuration reference (tuning values the gateway manages itself). Each value you set is still applied; nothing needs to change. `mcp-gateway init` no longer writes `meta_mcp.cache_ttl`, whose value equalled the default. (MIK-8044)
