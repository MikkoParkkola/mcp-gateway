- **A config write on a gateway with auth on and no audit log is refused.** Startup already refuses that state; a discovery adopt now refuses it too, before anything is written or stored, and answers 503 with `audit_log_required` and the message "auth is on but no audit log is configured; config writes are refused". An env file that assigns a reserved `MCPGW_PENDING_SLOT_` name is now refused naming the env file and the line. (MIK-8860)
