- **An admin credential scoped to some backends no longer holds gateway-wide admin powers.** An admin API key whose `backends` named only `alpha`, or an Admin-role key-server token scoped to `alpha`, could still kill, revive or reload the whole gateway, read every session's and key's spend, read `/health` detail, operator events and control-plane export status, and act as control-plane Admin. Those powers now need an admin scoped to every backend; a scoped admin keeps admin breadth inside its scope (Activity on its backends, admin-only capabilities on its backends) and is Auditor on the control plane. A queued task ends when a reload lowers its caller's admin standing. See UPGRADING.
  Affects: 4.0.0 pre-release builds. Operator action: give an admin key or Admin-role token meant for the whole gateway `backends: ["*"]`.
