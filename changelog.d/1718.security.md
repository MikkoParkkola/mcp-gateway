- **Windows checks secret and trust files, and creates them owner-only.** Config, env, `file:` secret, TLS key, OAuth token and credential files are created with one grant to the gateway's account and refused on read when another account can read or change them. Trust files (TLS certificate and CRL, identity grants and journal, control-plane grants and policies) may be read by others but are refused when another account can change them. The refusal names every broken rule and prints the PowerShell repair for the file's class. A create on a FAT or exFAT volume, which would discard its ACL, is refused: no secret is written; the empty file is removed. A pipe or device is refused as not a regular file. See UPGRADING-4.0 item 99. (#1718)
