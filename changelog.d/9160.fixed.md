- **Redacting injected values from number-heavy answers no longer slows down as the value count grows.** The echo scrub compared every JSON number in a backend's answer against every injected value, parsing each value again for every number, so a 16 MiB number-heavy answer took about 15 s to scrub against 1,024 values, and stored answers are scrubbed again on every cache hit, idempotent replay and task read. Each value is now parsed once per value set into two lookup sets (exact integers and float bits), and `null`, `true` and `false` into three flags, so a number costs one lookup: the same answer now takes about 0.13 s (median of three release runs), and doubling the values no longer changes it. What is redacted is unchanged (MIK-9160).
