- **The memory-poisoning scanner's `scan_tools` match is case-insensitive on both sides, as documented.** The tool name was lowercased but the configured entries were not, so an entry with an uppercase letter (`STORE`) matched no tool and the memory-poisoning scan never ran for the tools it named, with no warning. Entries are now lowercased once when the scanner is built, so `STORE` scans `store` and `Store_Memory`. An empty entry, which as a substring matched every tool, and a whitespace-only entry, which matched none, are refused at load and on reload with an error naming `security.firewall.memory_poisoning.scan_tools[i]`, whether or not the firewall or the scanner is enabled. Lowercase lists, the default included, match exactly the tools they matched before. (MIK-9326)
  Affects: an operator who sets `security.firewall.memory_poisoning.scan_tools`.
  Operator action: remove any empty or whitespace-only entry; an entry with uppercase letters needs no change, but now produces findings for the tools it names.
