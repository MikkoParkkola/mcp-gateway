- **A rotated or revoked account grant no longer shows its old per-user tools.** When a managed account's grant rotated or was revoked, a listing could still present the catalogue fetched under the old grant: by name in `gateway_list_servers`, in `tools/list`, in HTTP `tools/resolve` or after `gateway_set_profile`. That happened when a publish of the old grant raced the gateway's account re-check, or when custody was busy. Every listing path now applies one rule: a held catalogue shows only while the request's own account read still matches it. Both writers of that index check the grant with a fresh read before they publish. A busy custody read hides per-user tools for that request; shared backends still list. After a busy read, per-user tools can stay hidden for up to the cold-fill retry backoff (60 s). Sends were never affected: each call resolves its own credential. (MIK-8995)
  Affects: per-user backends that use managed accounts, in 4.0.0 pre-releases. Operator action: none.
