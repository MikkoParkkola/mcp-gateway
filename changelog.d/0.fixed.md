- **A backend's `transport` key is refused with its reason and its fix.** The gateway never read
  it: the transport follows from `a2a_url` (or `url`, `http_url`, `ws_url`, `command`). Earlier
  docs and the 4.0.0-beta.4 notes still showed `transport: a2a` beside `a2a_url`, and 4.0 refused
  that file as an unrecognised key. The refusal now says the key was never read and to delete the
  line, and `mcp-gateway upgrade` deletes it. Every gateway.yaml example in the docs, README,
  upgrade fragments and `src/config` rustdoc is now loaded by a test, so an example 4.0 refuses
  fails CI. See `docs/UPGRADING-4.0.md` item 162.
