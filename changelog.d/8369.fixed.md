- **`GET /api/costs` URL-decodes its `?key=` selector and answers "no data" with 404.** A key name with a space or a reserved character was never matched, because the query was compared still percent-encoded; it is now decoded the way axum decodes every other query (`+` is a space). "No data for key" and "No data for session" answer 404 Not Found instead of 200, with the same body. An escaped spelling of `session` is refused 400 like `?session=`. See upgrading.d/8369.md. (MIK-8369)
  Affects: scripts calling `/api/costs`.
  Operator action: check for 404 instead of an `error` body on 200; send a literal `+` as `%2B`.
