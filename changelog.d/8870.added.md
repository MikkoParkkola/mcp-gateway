- The web UI answers every `/ui/...` link instead of 404: a deep link, a reload on a sub-page or a shared link now reaches a static page that sends you on to `/ui`, ready for the new UI's pages. The current UI is also reachable at `/ui/classic` and stays at `/ui` until the new UI replaces it. The new UI's files are served from `/ui/assets/` with long-lived caching and a strict Content-Security-Policy; unrouted `/ui/api/...` paths still answer 404. (MIK-8870)
