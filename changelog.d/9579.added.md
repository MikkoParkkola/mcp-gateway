- **Web UI: Overview › Status opens on six number tiles.** Calls and firewall blocks for the past day, each set against the day before it with a small trend line, and each a link into Activity (the blocks tile opens it filtered to blocked calls). Next to them: what share of calls the cache answered, which server was slowest over the past hour by its p95 (linked to that server), how many tools the servers offer in total, and Spend, which is not wired up yet. When the gateway has no number to give, the tile says why ("Not available yet", "Not counted on this gateway", or the failure) instead of showing 0. Phones see Calls, Firewall and From cache first; the other three fold under "More numbers". Each page of the new UI now draws first and only then starts reading its data. (MIK-9579)
