- **The Overview's needs-you list now shows sign-ins and open decisions.** `GET /ui/api/overview` adds a `sign_in` row for each server waiting for a person to sign in (in name order, after the refusals and before the budgets; a long name is cut to 256 bytes and marked `clipped`) and one `decisions` row with the open-decision count and the decision set's revision, right after the invalid-config row. The count is read from the decision set's held snapshot, so the overview never starts a discovery scan; when a decision source cannot be read the row is left out, never sent as zero, and `needs_you.decisions` is named in `degraded`. When rows fold past the cap of 20, `more.by_kind` counts the folded rows per kind. (MIK-9148)
