- **Web UI: Tools › Actions lets you try a tool.** Pick a tool, fill in a form built from its input schema, and run it as the signed-in key. The answer shows how long it took, the result, and the call's firewall steps with a link to its Activity record; a blocked, failed or timed-out call says so, and a call the gateway refused names its receipt. A tool that can change things asks first through the same confirmation every other deciding action uses, and the outcome is read out to screen readers. (MIK-9549)
