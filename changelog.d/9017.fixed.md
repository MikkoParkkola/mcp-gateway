- **A refusal inside a task's dispatch is now tied to its task in the audit log.** When the gateway refuses a task-augmented call while its worker dispatches it (a response-contract refusal, or a refused readmission), the task's settlement now writes a `task_settlement` record that says `refused`, with the code the task settled with, joined by trace to the worker's dispatch record. Before, that dispatch record carried only an `error` outcome and no task id, so the log alone could not tell a gateway refusal from a backend failure or tie it to the task. A backend's own error with the same code is not recorded as a refusal. (MIK-9017)
