- **The skills watcher no longer drops changed capability files under load.** It queued each changed `*.yaml` path in a 100-slot channel and silently dropped any path once the channel was full, so a burst of edits, or edits made while a regeneration pass was running, left those skills stale until a later edit touched the same file. Changed paths now collect in a set that never drops one; a pass that leaves changes behind logs one warning (`Skills watcher: N skill changes arrived during regeneration; deferred to the next pass`) and they are regenerated on the next pass. Paths still pending at shutdown are abandoned, and a steady stream of edits postpones the pass until it goes quiet, as before. (MIK-8690)
