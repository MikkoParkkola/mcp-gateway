- **A 2026-07-28 client over `serve --stdio` no longer caches a tool list without its surfaced backends' tools.** Such a client cannot be told the list changed (stdio has no `subscriptions/listen` yet), so a first `tools/list` that landed during startup warm-up left those tools out for the whole session. Its first `tools/list` now waits, up to 30 s, for each surfaced backend's first tool fetch; if the wait runs out it answers with the tools that are ready, never an error. A session that began with `initialize`, which is told of changes, does not wait. See UPGRADING-4.0 item 52. (MIK-9309)
