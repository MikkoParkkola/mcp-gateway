- **Relay detection follows a reload, not the setting the gateway started with.** `security.firewall.collusion`'s `sources`, `non_egress`, `allowed_flows` and `action` now apply live: a delivery is recorded under the action in force when it is delivered, and a relay is judged against the lists and action of the request that relays it. A gateway started with relay detection `off` can switch it on by reload, provided `window_secs`, `min_matches` and `common_principals` are unchanged; otherwise `security` reports as needing a restart. Copies delivered while detection was `off` are not held, so a relay of them is not seen. (MIK-8932)
  Affects: deployments using relay detection in 4.0.0 pre-releases. Operator action: none.
