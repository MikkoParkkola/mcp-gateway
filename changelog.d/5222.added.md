- **Restart advice in the web UI.** 4.0.0 does not restart itself. When a reload or a settings save leaves settings that only a restart applies, the bundled UI's answer says how to restart: `restart_advice` (the restart preview's own guidance line) and, on Unix, `start_command` (the running binary and its config file, quoted for a POSIX shell); or `start_refusal` alone when the configuration a restart would boot is refused at startup. The classic page shows the same.
