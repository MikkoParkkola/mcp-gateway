- **An OpenAPI import writes only the document that was previewed.** The import fetched the document a second time and wrote whatever it got, so an operator who approved read-only tools in the preview could end up with tools that write. The preview now answers a digest of the text it parsed, an import by address must send it back, and an import whose text no longer matches writes nothing (409). With capabilities switched off, or no capability directory, the import routes and the capability create route refuse (409) instead of writing files into a relative folder nothing loads. One document now always converts to the same tools, whatever order its maps come in. See UPGRADING.
  Affects: the web UI's OpenAPI import and capability create; callers of the import routes. Operator action: none for the classic page; a caller of the import route by address must send the preview's digest.
