- **Stopping a stdio backend can no longer signal another backend's processes.** The liveness
  check reaped an exited backend process while its process-group id was still kept for
  teardown. After a pid wraparound, a later stop could signal an unrelated group with the
  reused id. The check now sees the exit without reaping, so the id stays reserved until the
  backend's own teardown ends and reaps the whole group. A backend that fails to start now
  also ends descendants that outlived its main process. (MIK-8080)
