- **A served start settles a crashed config write before it serves.** `mcp-gateway serve` takes the config lock before it reads the config, then settles whatever a crashed writer left (its journal, an abandoned config-write file, a retired manifest) with the gateway's own audit log before any backend starts; a start that cannot settle it refuses with one sentence saying what to do, and for an older write the logged error line names the files and the steps to finish by hand. Constructors that build from a config path refuse a build beside an unsettled write, and a gateway opens its configured audit log while it is built.
  Affects: 4.0.0 pre-releases and earlier. Operator action: none unless a start refuses; then follow its sentence. Ignore the new `.gateway.yaml.lock` beside the config in version control.
