- **A surfaced tool on a per-user passthrough backend is always sanitized.** With `security.sanitize_input` on, a call by a surfaced tool's own name to a per-user backend (identity propagation) is no longer exempt from input sanitizing, even when the backend is `passthrough`; a null byte in its arguments is refused and other control characters are stripped, as for any other backend. Exempting it let the answer show whether the caller's own catalogue has the tool. `gateway_invoke` and `gateway_execute` targets keep the passthrough exemption. See `upgrading.d/8356.md`. (MIK-8356)
  Affects: deployments with `sanitize_input` on and a per-user `passthrough` backend whose tools are surfaced. Operator action: none; call such a tool through `gateway_invoke` to keep the exemption.
