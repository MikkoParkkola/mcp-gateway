- **A reload that only edits API keys no longer reports a restart as needed.** Adding, removing or changing a key in `auth.api_keys` (its rotation fields included) applies on the next request, but the reload used to report `auth` as waiting for a restart and the change as "NOT YET APPLIED". It now reports the change as applied. A change to any other `auth` setting still reports a restart. (MIK-9173)
