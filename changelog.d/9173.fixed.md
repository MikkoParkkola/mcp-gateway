- **A reload that only edits API keys no longer reports a restart as needed.** Adding, removing or changing a key in `auth.api_keys` (its rotation fields included) applies on the next request, but the reload used to report `auth` as waiting for a restart and the change as "NOT YET APPLIED". It now reports the change as applied. A key edit that would switch the gateway between one user and many is still refused, as before. A change to another restart-only `auth` setting, alone or together with a key edit, still reports a restart; `dashboard_session` applies live, as before. (MIK-9173)
