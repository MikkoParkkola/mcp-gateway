- A capability argument such as `{env.NAME}` is no longer expanded to the gateway's own secret: references are resolved in the capability template before caller values are substituted (MIK-7787).
  Affects: 3.x up to 3.5.1 and the 4.0.0 pre-releases. Operator action: where untrusted callers could call capabilities, rotate every secret the gateway process can read through `{env.*}` or `{keychain.*}`, including ones no capability template referenced.
