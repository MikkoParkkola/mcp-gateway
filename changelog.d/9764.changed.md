- **Every command that prints data has a JSON form, and `audit show` prints one JSON array.** `stats`, `get`, `hash-key`, `skills list`, `skills search`, `skills show`, `cap list`, `cap search`, `cap registry-list`, `cap validate`, `cap test`, `audit verify`, `provenance verify` and `dashboard-link` take `--json` and then print one JSON document on stdout, with `schema_version` 1 and the same keys every time; their output without the flag is unchanged. A verify command prints its verdict document whether the verdict passes or fails, with the exit code it has today. `dashboard-link --json` reports failures as the shared JSON error on stderr. `audit show` now prints its matching entries as one JSON array, `[]` when none match, instead of one pretty-printed object after another and a text line when empty. docs/CLI.md lists every command's JSON form.
  Affects: scripts that read `audit show`'s stream of objects or its "No entries found" line. Operator action: parse the output as one JSON array.
