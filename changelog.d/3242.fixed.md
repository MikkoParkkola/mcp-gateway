- A stdio backend whose npm package cache is damaged no longer stays dead until the cache is cleared by hand. A start that fails with a missing module (`Cannot find module`, `MODULE_NOT_FOUND`) clears the cache the gateway assigned to that backend and retries once. The cache is cleared at most once per successful start, and a cache set in the backend's own `env:` is never touched. The gateway also passes six non-secret npm settings from its own environment (`npm_config_allow_git`, `cafile`, `prefer_offline`, `offline`, `strict_ssl`, `loglevel`) to every backend, unless the backend sets the same one itself ([@terafin](https://github.com/terafin), [#1759](https://github.com/MikkoParkkola/mcp-gateway/pull/1759)).
