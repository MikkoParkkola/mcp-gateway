- **A gateway started with the firewall off now says that the cross-tenant read verdict still runs.** The verdict (`security.firewall.tenant_guard.cross_tenant_reads`) runs on its own switch whenever `tenant_guard.arg_keys` is set and the mode is not `off`, on every transport, whatever `security.firewall.enabled` says; ADR-029 said it stopped with the firewall. Behaviour is unchanged. With the firewall off and the verdict on, startup now logs one notice naming the mode and `cross_tenant_reads: off` as the way to stop it: a warning under `block`, where answers can be withheld, and an info line under `observe`. ADR-029 and UPGRADING-4.0 item 130 now state this scope. (MIK-9327)
