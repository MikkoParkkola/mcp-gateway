- **A call made with a key-server token names that token in its audit decision.** The decision record of every call that presented an exchanged token (meta calls, direct backend calls, task runs, input rounds) carries the token's jti and the transparency-log issuance row that minted it, by counter and entry hash, so an auditor can join a call to its mint. The `token.issued` row now also records the configured lifetime (`ttl_secs`) and the latest moment the token can expire (`expires_by`). A key-server call whose token cannot be found is still recorded, marked `token_unavailable`, and counted in `mcp_decision_token_unavailable_total`. Records written by earlier versions read as before.
  Affects: Rust code that builds `TemporaryToken`, implements `TokenStore::reserve`, or calls `OwnedCallerContext::new`; docs/UPGRADING-4.0.md lists each change. Operator action: none.
