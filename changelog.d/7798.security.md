With agent authentication on, a stream opened with an agent token is checked again at every delivery: once the token expires, the agent is removed or its key changes, the stream receives nothing more and ends without a closing message. A legacy GET /mcp stream also checks each queued notification as it writes it, for every credential kind, and a prompt left queued behind a dead credential fails at once instead of waiting out its timeout. With gateway authentication also on, a valid agent token can now listen on a public /mcp. Embedders building `AuthState` by hand must set its new `agent_auth` field (MIK-7798).
