- With agent authentication on, a stream opened with an agent token is now checked again at every delivery: once the token expires, the agent is removed or its key changes, the stream receives nothing more and ends without a closing message. A GET /mcp stream also checks each queued notification when it writes it, for every credential kind, and a prompt queued behind a dead credential fails at once instead of waiting out its timeout. With gateway authentication also on, a valid agent token can now listen on a public /mcp (MIK-7798).
  Affects: deployments with agent authentication on, and every GET /mcp stream opened with a credential. Operator action: none; clients re-subscribe with a fresh token when a stream ends, and library users who build `AuthState` by hand set its new `agent_auth` field.
