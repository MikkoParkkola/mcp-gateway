- The `-full` image variant takes per-deployment packages and startup steps. Started as root, its entrypoint installs the apt packages `EXTRA_APT_PACKAGES` names (non-interactively, bounded by `EXTRA_APT_TIMEOUT`), runs executable `*.sh` and sources executable `*.envsh` files from `/docker-entrypoint.d`, then runs the gateway as uid 1001 with only its own groups. A failed install or drop-in stops the container. The image still declares `USER gateway`, and its default command is unchanged ([@terafin](https://github.com/terafin), [#729](https://github.com/MikkoParkkola/mcp-gateway/pull/729)).
