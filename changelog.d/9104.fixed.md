- **The web UI preloads its other screens even on a busy device.** After the first page paints, the shell preloads the other screens when the browser is idle, so the command palette lists their actions and a later visit opens at once. It asked for idle time with no deadline, so a browser that never saw the page as idle could hold the preload back indefinitely. The preload now starts within two seconds of the first paint either way. (MIK-9104)
