- **Context integrity's Strip delivers only text it can prove clean, and withholds the rest.** A Strip decision used to drop only lines holding one of four fixed phrases and then mark the answer stripped, so an instruction worded otherwise, a key or credentials file, or text past the 64 KiB classification sample went through unchanged. Strip now removes every line the kernel's detectors flag, and delivers the result only when the classification saw the whole result, every finding came from the text, none is guarded material, and a fresh scan of what is left finds nothing; otherwise the answer is withheld and recorded as `refused`, as a Deny is. On a tool result it works on the text items only. The final check reads the answer exactly as the gateway sends it, every string in every field, so an instruction in a field the gateway carries across (such as a round's `resultType`) withholds the answer under Strip and under Summarize alike. A withheld Strip's explanation now says it was withheld.
  Affects: 4.0.0 pre-releases and earlier. Operator action: none. Under `team_shared`, a result holding guarded material is now withheld rather than delivered.
