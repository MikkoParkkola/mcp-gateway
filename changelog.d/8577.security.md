- **WebSocket backends no longer trust the distrusted emSign intermediates.** The Mozilla root set bundled for WebSocket backends, `webpki-roots`, is updated to 1.0.10 (RUSTSEC-2026-0381). `rustls-webpki` 0.103.16 fixes how distrusted intermediates are handled (RUSTSEC-2026-0382); it checks certificate chains for WebSocket backends and, on Linux, for HTTPS backends. `webpki-root-certs` is updated to 1.0.10 too (RUSTSEC-2026-0383); native builds do not link it. HTTPS backends take their trust anchors from the operating system (the system store on Linux; the OS verifier on macOS and Windows), which this does not change. (#8577)
  Affects: 2.0.0 up to 3.5.1 and the 4.0.0 pre-releases. Operator action: none for a backend with a publicly trusted certificate; a WebSocket backend whose certificate chains through an emSign intermediate now fails its TLS handshake and needs a certificate from another authority; for HTTPS backends, keep the host's CA bundle updated, since the distrust reaches them through the operating system.
