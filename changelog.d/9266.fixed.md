- **A call to a backend that does not exist no longer reads as allowed in the decision record.** A `gateway_invoke` (on `/mcp`, stdio or in-process) naming a backend the registry does not hold used to record `decision.kind: default_allow` and `outcome: error`. It now records `not_found` and a refusal (`denied`) with the miss's -32001 code, as a scoped key's missing name already did, so the Activity "blocked" filter shows it. The answer the caller gets is unchanged. A backend that a reload removes between the gate and the dispatch still records the plain error. (MIK-9266)
