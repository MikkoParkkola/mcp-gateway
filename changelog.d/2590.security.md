- **Key-server OIDC URLs must be HTTPS off this machine.** A `key_server.oidc` issuer,
  `jwks_uri` or `discovery_url` that is `http://` to a non-loopback host refuses to start, and
  a token naming such an issuer is refused; before, the issuer only logged a warning, so a
  network attacker could swap the signing keys. Loopback `http://` is allowed and now works.
  See UPGRADING-4.0 item 116. (#2590)
  Affects: 3.x up to 3.5.1 and the 4.0.0 pre-releases started with such a URL and only warned, but their key and discovery fetches already refused non-HTTPS URLs and redirects, so no key swap over cleartext was reachable. Operator action: use `https://` for every `key_server.oidc` URL, or a loopback host for local testing.
