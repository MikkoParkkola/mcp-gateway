- **Key-server OIDC URLs must be HTTPS off this machine.** A `key_server.oidc` issuer,
  `jwks_uri` or `discovery_url` that is `http://` to a non-loopback host refuses to start, and
  a token naming such an issuer is refused; before, the issuer only logged a warning, so a
  network attacker could swap the signing keys. Loopback `http://` is allowed and now works.
  See UPGRADING-4.0 item 115. (#2590)
