- **One read for the web UI's Overview page.** `GET /ui/api/overview` (admin only) returns the first screen in one call: server and tool totals, uptime and version; the first 24 servers by name with the rest counted; needs-you rows for every daily budget at or past its configured Notify percent (default 80); the newest five admin actions from the transparency log; and whether an API key exists. Every list is capped, so the body does not grow with the number of servers. A section the gateway cannot know yet is left out of the response rather than sent as zero, and a source that fails to read is named in `degraded`. Call counts, the flow map, chart markers, server states and the invalid-config row join as their sources land; sign-in and pending-decision counts are not available in this version. (MIK-8869)
