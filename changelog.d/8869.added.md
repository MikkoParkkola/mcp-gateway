- **One read for the web UI's Overview page.** `GET /ui/api/overview` (admin only) returns the first screen in one call: server and tool totals, uptime and version; the 24-hour call, block and error totals, with the previous 24 hours when counting covers them; the top 24 servers by calls, each with its operator state and reason, and the rest counted; the top 48 caller and server flows; the chart markers of the last day; needs-you rows for a refused config reload (`invalid_config`), for refused edits and for servers the runtime policy denies (`refused`), and for every daily budget at or past its configured Notify percent (default 80); the newest five admin actions from the transparency log; and whether an API key exists and whether any tool has been called in 30 days. Every list is capped, so the body does not grow with the number of servers. A section the gateway cannot know yet is left out of the response rather than sent as zero, and a source that fails to read is named in `degraded`. The counter fields are left out when there is no counter store, and named in `degraded` when the clock cannot be read. Sign-in and pending-decision counts are not available in this version.
