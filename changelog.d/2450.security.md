- **A repeated task call is checked against current policy.** A task-augmented `tools/call` repeated with the same idempotency key and body used to be answered from the stored task without the invocation policy (identity grants, attestation, kill switch, capability disable, profile, withheld tools). The policy now runs before that answer, as it does before a synchronous replay; a fresh task is still checked by its worker. (#2450)
