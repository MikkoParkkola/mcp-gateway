- **Six key-free map tools, paced per host.** `geocode` (Open-Meteo), `nominatim_search` and `nominatim_reverse` (Nominatim), `photon_search` (Photon), `overpass_nearby` (Overpass) and `osrm_route` (OSRM demo, driving) ship under `capabilities/maps/`, pinned and cached, each sending an identifying User-Agent. A provider can now declare `rate_limit: { interval_ms: <1..600000> }`: every call to that host, from any capability on it, is admitted at most once per interval per gateway process, a paced call is one request with no redirect followed, and a call inside the interval is refused at once with the wait in its text. A capability can declare `attribution: "<text>"`, set on every successful result at both the backend and `gateway_invoke` exits; OpenStreetMap tools credit "© OpenStreetMap contributors" and Open-Meteo tools "Data by Open-Meteo.com (CC BY 4.0)".
