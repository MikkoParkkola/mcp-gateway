- **Changing a server's command or address keeps the rest of its transport.** An update through the web UI that set a new command or address replaced the whole transport, so a working folder, a protocol version, an explicit HTTP mode or an A2A agent card path set in gateway.yaml was silently dropped. Now a new value of the same kind changes only that value, and an HTTP address given to an A2A server keeps it A2A with its card path; changing the kind (a command on a URL server, a websocket address on an HTTP server) still starts the transport fresh. An A2A server whose card path is not the default one cannot be moved to another scheme, host or port this way: the update is refused with a 422, because the kept path could carry a token to a host nobody chose for it; change the address and the card path together in gateway.yaml.
  Affects: 4.0.0 pre-releases. Operator action: if you changed a server's command or address in the web UI on a pre-release, check gateway.yaml for a cwd, protocol_version, streamable_http or a2a_agent_card_path that went missing.
