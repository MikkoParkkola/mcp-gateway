- **The `-full` image's npm carries undici 6.29.1 (CVE-2026-109869).** The image pins the packages it vendors into npm's tree, and its `undici` pin moves from 6.29.0 to 6.29.1, which fixes a denial of service via an unhandled stream error on excessive content. The copy sits inside npm's own tree (`/usr/lib/node_modules/npm/node_modules/undici`). npm reaches it only for its own registry traffic, such as `npx` fetching a stdio backend's package; the gateway itself never loads it. The default image carries no Node.js and is not affected. (MIK-8820)
  Affects: the `-full` image of every release whose Dockerfile pins undici 6.29.0, which is 4.0.0-beta.3 and later 4.0.0 pre-releases. Operator action: pull the next `-full` image; no config change.
