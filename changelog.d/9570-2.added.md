- **A server's page has its Settings tab.** Connection shows the server's transport. Secrets lists each slot that holds a reference (its name, whether it is an environment variable or a header, and the reference, never a value); an environment variable has Replace, a password field whose Save stores the new value in the secret store and says it was replaced only when the gateway confirms it, keeps what was typed after a refusal, and leaves no copy on the page once the form closes. A header is changed in gateway.yaml. Who can use it lists every key with a link to its page and what it reaches of this server: all of its tools, tool restrictions, or none (an empty allowlist reaches no tool). (MIK-9570)
