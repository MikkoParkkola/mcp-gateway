- **The classic web UI's Remove button and capability buttons work again.** They were built as inline `onclick` handlers holding the name as JSON, whose opening quote ended the HTML attribute, so a click had nothing to run; the capability page's Save and Revert were also replaced at load by an unused editor's functions. Names now travel in `data-` attributes read by one click listener, `esc()` escapes both quote characters, and the unused editor is removed. (MIK-8949)
