- **`add` keeps the comments in gateway.yaml.** `mcp-gateway add` re-serialised the whole config,
  which dropped every comment, including the warning `init` writes next to the generated
  `bearer_token`. `add` now writes the new backend into the file's text under `backends:`, or
  adds that key at the end, and leaves the rest of the file as it was. It does this only when
  the edited file loads to exactly the old config plus that backend; otherwise it rewrites the
  file as before.
