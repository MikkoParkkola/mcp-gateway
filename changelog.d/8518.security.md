- **Identity grants for `api_key:<name>` now match only an authenticated API key of that name.** An identity grant written for `api_key:<name>` no longer matches the static bearer (`bearer`), the dashboard session (`dashboard`), the auth-off caller (`anonymous`) or the public-path caller (`public`), and a `key_server.oidc` provider whose `issuer` is a reserved grant authority (`mtls`, `agent_oauth` or `api_key`) is refused at load. (#3950, MIK-8518)
  Affects: gateways with identity grants whose subject authority is `api_key`, and gateways whose `key_server.oidc` names a reserved issuer. Operator action: give each affected caller a named API key in `auth.api_keys` that the grant names, turning auth on where it is off, and point any reserved `issuer` at the provider's real https issuer URL.
