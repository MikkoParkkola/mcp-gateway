- **On Windows, a private save keeps a file's owner or refuses.** A config or state save that writes an owner-only file (OAuth storage, history, journals, certificates and the like) used to replace a file another account owned with one owned by the gateway's account. It now refuses with `foreign-owner`, naming both accounts, before writing anything, as Linux and macOS already do; a file whose owner cannot be read is refused with `descriptor-unreadable`. Files the gateway's account owns save as before, and so does any file on a volume that keeps no access lists (FAT, exFAT).
  Affects: 4.0.0 pre-releases. Operator action: none, unless a save reports `foreign-owner`; then run the gateway as the file's owner, or give the file to the gateway's account.
