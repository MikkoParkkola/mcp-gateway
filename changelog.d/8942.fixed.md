- **A saved daily total that no run could hold restores as zero, with a warning.** On start the
  gateway puts today's spend back from `costs.json`. A value that was negative, infinite or too
  large for a micro-USD count (only a damaged or hand-edited file holds one) used to saturate
  into a cap that refused every call until the day rolled. That row now restores as zero, and a
  warning names `costs.json`, the row and its value. (MIK-8942)
