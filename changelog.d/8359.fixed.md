- **Three upstream-session wake tests no longer fail when the machine is busy.** They timed the reconnect (a 5 s poll and two 700 ms bounds) to show a revival cut a wait, so a slow reconnect under load read as a missed wake. The task now records what ended each wait (a revival or its own timer) in test builds only, and the tests assert that cause. No behaviour of the gateway changes. (MIK-8359)
  Affects: contributors running the full test suite on a loaded machine.
