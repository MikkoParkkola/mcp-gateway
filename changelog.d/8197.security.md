- **The Windows OAuth login no longer goes through cmd.exe.** The authorization URL was opened with `cmd /c start`, which split it at the first `&`: interactive login opened a truncated URL, and a hostile authorization server could put `&<command>` in its `authorization_endpoint` to run that command as the gateway's user. Windows now opens the URL with `rundll32 url.dll,FileProtocolHandler`, which hands it to the browser unparsed. On every platform only an `https` (or loopback `http`) URL is handed to a browser launcher, the launcher no longer shares the gateway's stdin and stdout, and the "visit this URL" prompt is always shown, on stderr, in case the launch was blocked. (MIK-8197)
