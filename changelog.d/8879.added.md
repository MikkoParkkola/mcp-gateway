- **The new web UI has a Tools screen.** Tools › Status lists every tool the gateway offers, A to Z, with its server and description. A search over names and descriptions and a server picker narrow it, and the search survives a visit to a tool and back. Each tool's name opens its description, its read or write class and its input schema in place, and each tool has its own page. Everything works from the keyboard. The most-called list and Try a tool follow when their data is available. (MIK-8879)
