- **Governance audit records are timed.** Each control-plane audit record now carries a `timestamp`, like invocation and admin-action records already do, so the Activity page can place config changes among calls in time order. Records written before 4.0 have none; the Activity list puts them just before the oldest timed governance record, in file order. The hash chain, `audit verify` and the SIEM export (which forwards each record whole) accept a log that mixes both. (MIK-8855)
