- **Undated cost, profile and breaker records on a host clock that reads before 1970.** `CostRecord.timestamp`, session `started_at`, `EnforcerSnapshot.taken_at`, profile `created_at` / `last_used_secs`, `WindowStats` totals and `CircuitBreakerStats.last_trip_ms` are now `Option` (`None`, serialized `null`, where the clock could not date them) instead of 0, `KeyCost::budget_status` answers a new `BudgetStatus::Unknown`, pool idle and breaker-open timing run on the monotonic clock, and an upstream cancel claimed while dark is written undated and sent once the clock reads. Affects 4.0.0 pre-releases only (MIK-8202).
