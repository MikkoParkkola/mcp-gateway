- **The web UI no longer creates an API key it cannot revoke, or one whose name could forge a log line.** Creating a key named `.` or `..` answers 422 `name_not_addressable` and writes nothing: a browser drops a `.` or `..` path segment, so the revoke route could never reach such a key. A name holding a control character is refused the same way, because it could start a forged line wherever the name is printed (such a key can still be revoked by its encoded address). A hand-written key with any of these names still loads, and the key list marks it `addressable: false`.
