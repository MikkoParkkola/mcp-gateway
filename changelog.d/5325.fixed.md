- **The web UI no longer creates an API key it cannot revoke.** Creating a key named `.` or `..`, or one whose name holds a control character, answers 422 `name_not_addressable` and writes nothing: a browser drops a `.` or `..` path segment, so the revoke route could never reach such a key. A hand-written key with such a name still loads, and the key list marks it `addressable: false`.
