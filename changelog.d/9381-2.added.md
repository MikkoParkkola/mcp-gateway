- **Contributors: mutation batches in one build.** `scripts/ci/mutants/run_mutants.py` gains a `schemata` mode: a batch lists `mutant!` IDs and the test rows each must fail, and the mutants workflow builds once with `--cfg mutants`, checks the IDs against the library's site listing, runs the rows with no mutant on, then runs each mutant's rows one process per row. A mutant counts as killed only when every row fails at its listed file and line. Hosted mutant runs now queue one at a time and record their wait. No change for users of the gateway. (MIK-9381)
