- Four limits accepted for the 4.0.0 pre-releases are closed (MIK-7881, #3068). With the tenant guard on, a quoted, double-encoded result cut short is read as far as it goes, so a document inside it is marked uninspected. With relay detection on, each pair keeps its own delivery times, so a stale copy plus a later re-delivery no longer excuses an egress, nor makes a witness, between them. On Windows, a refused grant-journal append says to check the journal's entries before it prints the repair commands. The manual events test stub refuses a `Content-Length` padded with vertical tab or form feed.
  Affects: the 4.0.0 pre-releases with the tenant guard or relay detection on, and Windows grant-journal refusals. Operator action: none.
