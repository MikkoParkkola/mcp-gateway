## The `filesystem`, `memory` and `sequential-thinking` registry entries move to `1.0.0`

**Startup:** no notice

What you gain: the three reference servers the registry installs are no longer
pinned to a version npm has deprecated. Upstream's `1.0.0` is its final
release of these servers, and the registry's live check passes again.

Who is affected: anyone who runs `mcp-gateway add filesystem`, `add memory` or
`add sequential-thinking` from now on, and every new `mcp-gateway init`
(it enables `memory` and `sequential-thinking` by default). A config you wrote
earlier keeps the pin it has; nothing changes for it until you change the
version yourself.

What changes on `1.0.0`:

- **`sequential-thinking` stops being read-only.** Its tool used to report
  itself as read-only and idempotent; it now reports neither, which is accurate
  for a tool that keeps the thought history. The gateway reads that hint in two
  places. A `gateway_list_tools` call with `role: selector` or `role:
  extractor` no longer lists the tool (it appears under `role: action` and with
  no role). And its results are no longer eligible for the response cache.
- **`memory` is stricter and starts empty.** A relation that names an entity
  which does not exist is now refused with `Entity with name <name> not found`;
  version `2026.8.31` stored it. With no `MEMORY_FILE_PATH`, the graph file lives
  next to the installed package, and `npx` installs each version into its own
  directory, so an entry added on `1.0.0` begins with an empty graph. `~` is now
  expanded in `MEMORY_FILE_PATH`.
- **`filesystem` waits for roots.** Tool calls wait for the client's roots, a
  client that withdraws its roots withdraws the server's access, and a server
  started with no directories and no roots fails with a visible error. Roots
  from the client still replace the directories on the command line, as before.

What you keep: every other registry entry, and every config that already
exists.

What to do:

- Nothing, to keep working.
- To move an existing entry, run `mcp-gateway add <name>` again or change the
  version in your config to `1.0.0`.
- Before moving `memory`, set `MEMORY_FILE_PATH` to an absolute path (copy the
  old graph file there if you want to keep it).
- If a client lists tools by role and used to find `sequential-thinking` under
  `selector` or `extractor`, list under `action` or with no role.
