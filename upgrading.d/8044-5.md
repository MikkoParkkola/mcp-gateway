## The library is internal to the binary

**Startup:** no notice, a change to the Rust library's documented API, not to the binary

What changed: `mcp-gateway` is a command-line gateway. Its Rust library target
exists so the binary, its integration tests and its benches share one build.
In 4.0 every crate-root item is `#[doc(hidden)]`, the crate documentation says
the library is internal and unsupported, and CI fails on any new documented
crate-root item (`scripts/release/check_surface_inventory.py`, and a rustdoc
step that asserts the crate page lists nothing).

What you keep: every path still compiles where it did. Nothing was renamed
or removed by this change.

What you lose: any promise about those paths. A hidden item may change or
disappear in any release, a patch release included, without an entry here.
crates.io lists no crate that depends on `mcp-gateway`; if you build on the
library, pin an exact version and open an issue describing what you use, or move to
the supported surface: the binary, its configuration and the MCP wire protocol.
