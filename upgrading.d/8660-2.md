## Token exchange no longer follows a token endpoint's redirect

**Startup:** no notice

**What you lose.** A token endpoint configured at a URL that redirects (a moved path, an `http` to
`https` hop, a load balancer's 307) no longer works through the redirect: the exchange fails with
`token-exchange endpoint returned HTTP 307 Temporary Redirect, a redirect, which is not followed`.

**What you gain.** A 307 or 308 re-sends the request body, so following one posted the exchange form,
the caller's `subject_token` included, to whatever the redirect named. That no longer happens.

**What you do.** Set `token_exchange_endpoint` to the URL the endpoint redirects to.
