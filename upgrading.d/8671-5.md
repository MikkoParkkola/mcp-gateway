## The validator output format is ValidatorOutputFormat

**Startup:** no notice

**What you gain.** The type's name says what it is: the `validate --format` values (`text`, `json`, `sarif`); cli::output::OutputFormat keeps its name.

**What you lose.** The old path `mcp_gateway::validator::OutputFormat` no longer resolves, so a `use` of it fails to compile.

**What you do.** Replace `mcp_gateway::validator::OutputFormat` with `mcp_gateway::validator::ValidatorOutputFormat`. The the CLI flag values are unchanged.
