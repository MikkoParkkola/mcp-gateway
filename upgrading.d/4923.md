## Shipped templates give the gateway its whole stop: the stop timeout + 1 s

**Startup:** no notice, nothing changes at startup

The gateway's stop is bounded by `server.shutdown_timeout` (30 s by default), counted from the stop signal.
Every shipped template ended it sooner with a SIGKILL, which cut the state saves or the backend stop short.
Each now waits the timeout + 1 s:

| Template | Before | Now |
|---|---|---|
| deploy/single-node/mcp-gateway.service | `TimeoutStopSec=30s`, `KillMode` unset (`control-group`) | `TimeoutStopSec=31s`, `KillMode=mixed` |
| deploy/single-node/docker-compose.yaml | no `stop_grace_period` (Docker's 10 s) | `stop_grace_period: 31s` |
| deploy/single-node/com.mikkoparkkola.mcp-gateway.plist | no `ExitTimeOut` (launchd's 20 s) | `ExitTimeOut` 31 |
| Helm chart | no `terminationGracePeriodSeconds` (Kubernetes' 30 s) | `config.server.shutdown_timeout` + 1 s, 31 s by default |
| deploy/kubernetes/enterprise-alpha/base/deployment.yaml | no `terminationGracePeriodSeconds` (30 s) | `terminationGracePeriodSeconds: 31` |
| `docker run` examples in the docs | Docker's 10 s | `--stop-timeout 31` |

`KillMode=mixed` sends the SIGTERM to the gateway only, so it closes each stdio backend's stdin and stops the
backends in order; with `control-group` every backend got the SIGTERM at the same moment as the gateway. At
the timeout systemd still SIGKILLs every process left in the unit.

The Helm chart reads `config.server.shutdown_timeout` with the gateway's own grammar (one whole number with an
optional unit ms, s, m or h, at most 100 years). A value the gateway would refuse at start now fails the render,
naming the setting; every value the gateway accepts renders as before, plus the grace.

**Action:** none for a fresh install from the templates. If you run a copy of a template, give it the values above.
If your configuration raises `server.shutdown_timeout`, raise the grace with it (the Helm chart does this itself
for a timeout set in its `config`; a config file or environment file you mount is out of its sight).
