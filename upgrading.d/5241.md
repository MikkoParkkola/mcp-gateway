## The tls commands refuse to replace existing output

**Startup:** no notice

`mcp-gateway tls init-ca`, `tls issue-server` and `tls issue-client` now stop with an
error when `<stem>.crt` or `<stem>.key` already exists under `--out` (for `issue-client`
the stem comes from `--cn`). Nothing is written. A script that reran one of these commands
to rotate a CA or a certificate in place must now move the old files aside first, or
write the new ones to another `--out`.
