## `--help` lists only the commands and flags 4.0 keeps

**Startup:** no notice

What you gain: a shorter `--help` that shows the commands you use. The
internal commands `kubernetes`, `ranking`, `runtime` and `trust`, and the
`-C/--capabilities` flag of `skills generate` and `tool invoke`, `tool list`,
`tool inspect` and `tool completions`, are no longer listed.

What changes: only the help text. Every call that worked before still
works: a hidden command still runs (`runtime` still only in a build with the
`runtime-substrate` feature), and `mcp-gateway kubernetes --help` still
documents it. The `-C` flags still parse. `add`, `remove`, `list` and `get`
no longer declare their own `--config/-c`; they read the global `--config`
(or `MCP_GATEWAY_CONFIG`), else `./gateway.yaml`, as they already did.
`--config <file>` works before or after the command name, and a flag still
wins over the variable.

What to do: nothing, unless a tool reads the top-level `--help` to find
these commands or flags. A hidden command's own `mcp-gateway <command> --help`
still lists it; the `-C` flags are in no help text, so name them directly.
