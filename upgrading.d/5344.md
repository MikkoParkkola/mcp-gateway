## A config write waiting for its audit record names a remedy this build ships

**Startup:** no notice

- What changes: a config write that finds an earlier write still owing its audit record is refused with "A config write is waiting for its audit record. Start or restart the gateway with `mcp-gateway serve` on this same config file, with the audit log that write was bound to configured and reachable: its startup settles the write or says why it cannot. Once it has started, run this again." The gateway's startup settles the pending write before it serves, or refuses with the reason it cannot. Earlier builds named `mcp-gateway audit settle --abandon`, which 4.0.0 does not ship.
- What stays: when the refusal appears, and every other refusal, are unchanged.
