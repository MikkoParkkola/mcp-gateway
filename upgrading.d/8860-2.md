## Names starting MCPGW_PENDING_SLOT_ are reserved

**Startup:** no notice

- What changes: the config writer checks a save before it stores any secret by loading the new file with each secret standing in as `env:MCPGW_PENDING_SLOT_<n>`. A gateway.yaml whose text names `MCPGW_PENDING_SLOT_`, or an env file that assigns such a name, is refused at load, so no config can reach a stand-in value.
- What stays: every other variable name loads as before.
