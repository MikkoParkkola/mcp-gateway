## Names starting MCPGW_PENDING_SLOT_ are reserved

**Startup:** no notice

- What changes: the config writer checks a save before it stores any secret by loading the new file with each secret standing in as `env:MCPGW_PENDING_SLOT_<n>`. A gateway.yaml that references such a name (`env:MCPGW_PENDING_SLOT_…` or `${MCPGW_PENDING_SLOT_…}` in a key or value), or an env file that assigns one, is refused at load, so no config can reach a stand-in value. The refusal names the reference and its line. A comment that only mentions the prefix is not a reference and loads as before.
- What stays: every other variable name loads as before.
