## A blank certificate name names no one

**Startup:** no notice, a request presenting such a certificate is refused (401, JSON-RPC -32000)

A SAN URI or CN made only of spaces or tabs is treated like an empty one.
A certificate whose only names are blank is refused, exactly as a
certificate with no name already was, and a blank SAN URI no longer takes
precedence over a real CN when the gateway picks the agent the certificate
names. Every other value is kept exactly as written, so `" admin "` stays
a different name from `admin`.
