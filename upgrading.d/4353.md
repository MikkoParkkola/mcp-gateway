## A config write that cannot be made in place is refused

**Startup:** no notice, a change to config writes only

What you gain: `gateway.yaml` keeps the layout you wrote. A save either
changes just the lines it must, or writes nothing and says why.

What you keep: a block-style file, with or without comments, is edited in
place as before, including one with no `backends` key yet and an empty
one. `--force` on the CLI still rewrites the whole file.

What you lose: a comment-free file the in-place edit cannot handle was
rewritten whole before; now the write is refused. That is a file whose
`backends` is a flow mapping (`backends: {a: {...}}`), or one where the
change would remove an anchor another backend aliases. The web UI answers
409 and writes nothing; the CLI command fails and names `--force`.

What to do:

- Nothing, for a block-style file.
- Otherwise, make the change by hand, or rewrite the file once with the CLI
  and `--force` (key order, quoting, flow style and anchors are not kept),
  after which saves edit it in place.
