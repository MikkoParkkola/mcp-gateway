## A waiting caller's busy-lock error matches the login caller's

**Startup:** no notice

**What you gain.** Every caller that hits a busy credential lock gets the same
answer: JSON-RPC code -32000, "Backend unavailable: credential lock busy: ...",
safe to retry. Before, a caller that waited on another caller's login got
-32603 and an "OAuth error: " prefix for the same condition.

**What you lose.** Nothing in configuration. A client that keyed on -32603 or on
the "OAuth error: Backend unavailable: credential lock busy" text for this rare
case sees the new code and text.

**What you do.**

- Nothing, unless a client matches that old code or text; match -32000 or the
  "credential lock busy" text instead.
