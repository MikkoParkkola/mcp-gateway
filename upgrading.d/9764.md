## `audit show` prints one JSON array; every data command has `--json`

**Startup:** no notice, nothing changes at startup

What you gain: a script can read every data command without parsing text.
`stats`, `get`, `hash-key`, `skills list`, `skills search`, `skills show`,
`cap list`, `cap search`, `cap registry-list`, `cap validate`, `cap test`,
`audit verify`, `provenance verify` and `dashboard-link` take `--json` and
print one JSON document with `schema_version` 1 and fixed keys. A verify
command prints its verdict document for a pass or a fail, with the same exit
code as before. docs/CLI.md lists each command's JSON form.

What you lose: `audit show` no longer prints a stream of objects or a "No
entries found" line. It prints one JSON array, `[]` when nothing matches.
Output without `--json` is unchanged for every other command.
