## Shadow radar asset ids change once for servers with a URL

**Startup:** no notice

- What changes:
  - An asset id of a server found with a URL no longer spells the URL out: it carries a digest keyed by the gateway's record key. Every such id changes once, at upgrade, so a consumer that keys first-seen and last-seen times by asset id sees each of those servers as new once.
  - Ids from the gateway then hold across restarts. Ids from `cap discover --shadow` and `doctor` hold once a gateway has created the record key, or `security.record_principal_key` is set; until then a report says its URL ids are for that run only. Neither command creates the key.
- What stays: ids of servers found without a URL (a command or a port) are unchanged, and the report's schema version is unchanged; it gains an optional `ids_note`.
