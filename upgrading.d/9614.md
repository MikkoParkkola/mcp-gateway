## LiveConfig::publish leaves the library API

**Startup:** no notice, nothing changes at startup

`LiveConfig::publish` swapped in a prepared generation and erased the configuration revision that config history
records versions under. Nothing in the gateway calls it, so it is now compiled for the crate's own tests only.
`LiveConfig::set` stays callable for test fixtures but is hidden from the documentation: it replaces the config and
erases the revision.
