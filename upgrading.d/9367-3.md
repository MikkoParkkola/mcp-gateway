## API key approval bindings

**Startup:** no notice

The public `mcp_gateway::config::ApiKeyBinding` type records `quota_principal`
and `digest_tag` for the admin key that approved a CLI key.
`mcp_gateway::config::ApiKeyConfig` adds two public fields:
`approved_by: Option<ApiKeyBinding>` and `cli_host: Option<String>`.

Library callers constructing exhaustive `ApiKeyConfig` literals must supply
both fields; use `None` for ordinary keys, or retain `..Default::default()`.
Existing configuration files need no change: both fields default to absent.
The reported host is display metadata and never grants access.
