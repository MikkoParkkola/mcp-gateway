## The usage snapshot lists every tool

**Startup:** no notice

What you gain: the web UI's tool list now carries each tool's calls in the
last 24 hours and the same hours of the day before, for every tool, and the
usage snapshot no longer drops all but the 10 most-called tools.

What changes:

- `GET /ui/api/tools` gives each tool `calls_24h` and `calls_prev_24h`, and
  the answer gains `counts_since`. `GET /ui/api/status` gives each server the
  same two counts, and the admin answer gains `counts_since`. A count is
  `null` when it could be low (calls folded into an overflow count, or no
  longer held), and every count is `null` when the call counters are not
  running.
- For a library user: `StatsSnapshot::top_tools` is no longer capped.
