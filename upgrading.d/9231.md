## A server can name its owner

**Startup:** no notice; refuses to start, only for an `owner` over 200 characters or with a control character (a newline, a tab)

What you gain: `backends.<name>.owner` records who looks after a server,
a team or a person, and the web UI shows it in the server's details. It is
display only: a reload that changes only an owner takes effect at once and
leaves the server running.

The owner appears only in the admin-only server view, never on the status
route every caller can reach.
