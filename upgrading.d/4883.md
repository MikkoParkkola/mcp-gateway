## Building from source needs Rust 1.100

**Startup:** no notice

The minimum supported Rust (`rust-version` in `Cargo.toml`) is now 1.100, up from 1.95. The release
workflows, CI and the container image build on 1.100.0. This changes how the gateway is built, not
how it runs: a binary built before or after behaves the same, and nothing in a running install
needs an action.

- `cargo install mcp-gateway` and a build from a source checkout need Rust 1.100 or newer; older
  toolchains stop at cargo's version check with a message naming 1.100.
- A checkout now carries a pin check (`scripts/ci/check_toolchain_pin.py`) that keeps CI, the
  Dockerfile builder and the minimum Rust on one compiler.
