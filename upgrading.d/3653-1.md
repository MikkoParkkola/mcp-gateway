## The library's `Error` gains `CliCredentialRefused`

**Startup:** no notice

**What you lose.** Code built against the `mcp-gateway` library that matches `Error`
exhaustively no longer compiles until it handles the new variant. A CLI capability's refusal
of its credential used to arrive as `Error::JsonRpc` with code 401.

**What you gain.** Only the gateway builds `CliCredentialRefused`, so a backend that answers
with its own JSON-RPC error code 401 no longer triggers a managed account's forced refresh or
reconnect offer. A backend that refuses with HTTP 401, whatever its body says, now does. Callers
still see code 401 for a CLI refusal.

**What you do.** Add an arm for `Error::CliCredentialRefused { message }` where you match
`Error` exhaustively. Nothing changes for gateway operators.
