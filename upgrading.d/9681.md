## Completion scripts for four shells; tls `--output`; the UI API version in `--version`

**Startup:** no notice, nothing changes at startup

What you gain: `mcp-gateway tool completions <shell>` writes a script for bash,
zsh, fish or PowerShell that completes every command, flag and closed value
list, tool names included, at every depth. Every command's help ends with an
example. `mcp-gateway --version` prints `mcp-gateway <version> (UI API 1)`, the
number `GET /ui/api/status` also serves. Releases ship a man page,
mcp-gateway.1, which Homebrew installs.

What you may notice: regenerate your completion script after upgrading, since
the old scripts were written by hand and covered fewer commands. The tls
commands name their output directory `--output`; `--out` still works. elvish is
no longer offered by `tool completions`. `cap import` and `cap import-url` no
longer show `-p` in their help (it reads as `--port` elsewhere); `-p` still sets
`--prefix` on both.
