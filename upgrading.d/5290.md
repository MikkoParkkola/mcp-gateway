## Server names with a control character, or named `.` or `..`, are refused

**Startup:** no notice, the start is refused with its own error, which names the server; refuses to start, only for such a name

4.0.0 refuses to start on a `gateway.yaml` whose server name, or `capabilities.name`, holds a control character (a line feed, a tab, any Unicode Cc character), or is `.` or `..`. Fix it by renaming that server in the file. The error names the server with its control characters escaped, so the message itself cannot start a forged log line. No address can reach a server called `.` or `..`, because clients fold those path segments before the request is sent, so such a server could never be managed or called. A reload that brings in such a name is refused, and the running configuration stays. Names with a space or a non-ASCII letter load as before.
