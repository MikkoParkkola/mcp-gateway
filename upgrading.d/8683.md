## `gateway_search` queries are capped at 256 characters

**Startup:** no notice

**What you gain.** One request can no longer make glob matching take
combinatorial time; the matcher is bounded and the query length is capped.

**What you lose.** A query over 256 characters (counted before lowercasing)
is refused with -32602 instead of searched. The message names the limit and
never echoes the query.

**What you do.** Shorten such queries. The longest bundled `server:tool`
reference is far under the cap (the test
`every_bundled_capability_reference_is_under_the_cap` checks it), so only a
free-text query that long is affected.
