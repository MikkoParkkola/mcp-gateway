## Cost windows survive a restart

**Startup:** no notice, one warning when a saved history cannot be read

What you gain: the per-key 24 h, 7 d and 30 d spend windows, and the
history behind the cost charts, come back after a restart instead of
starting at zero. The time the gateway was down stays a gap.

What changes: a new file, `spend-history.json`, sits in the data directory
beside `costs.json`. It holds 30 days of spend per API key, per hour and per
local day, plus the spend of calls with no API key and one summed overflow
for keys past the first 512 by spend. It holds numbers, dates, key names and
a fingerprint of each name, never a session id or a tool argument. It is
written in the same save as `costs.json` (every 5 minutes and at shutdown)
and is always owner-only (0600). A saved key's history attaches to the
configured key with the same full name; the history of a key you removed or
renamed stays in the overflow, so totals stay exact. Per-tool breakdowns are
not saved.

What to do: nothing for ordinary use. Include `spend-history.json` in the
backups that already hold `costs.json`. An older build ignores the file, so a
rollback keeps working.
