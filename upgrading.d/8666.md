## Three public mirror types are removed from the library

**Startup:** no notice

What you gain: one type per job. The key-server policy matches on the rule
types the config already defines, and `runtime.availability` is held as the
planner's own `RuntimeAvailability`.

What you keep: every config file. `key_server.policies[].match`,
`key_server.policies[].scopes` and `runtime.availability` keep their keys,
defaults and serialized form; `local_process` still defaults to `true`.

What you lose: three names in the Rust library API.

| Removed | Use instead |
|---|---|
| `mcp_gateway::key_server::policy::MatchCriteria` | `mcp_gateway::config::PolicyMatchConfig` |
| `mcp_gateway::key_server::policy::PolicyScopes` | `mcp_gateway::config::PolicyScopesConfig` |
| `mcp_gateway::config::RuntimeAvailabilityConfig` | `mcp_gateway::runtime::RuntimeAvailability` |

`RuntimeAvailabilityConfig::runtime_availability()` converted to
`RuntimeAvailability`; the value is now that type already.

What to do:

- Nothing, if you only run the gateway.
- In Rust code that links the library, rename the three types as above.
