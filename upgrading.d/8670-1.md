## The sandbox launcher uses the runtime substrate type

**Startup:** no notice

**What you gain.** One substrate type across the runtime compiler and the attestation launcher, so a sandbox's substrate no longer has to be translated between two enums.

**What you lose.** The path `mcp_gateway::attestation::Substrate` no longer resolves, so a `use` of it fails to compile.

**What you do.** Replace `mcp_gateway::attestation::Substrate` with `mcp_gateway::runtime::Substrate`, `GvisorLinux` with `GVisor`, and `AppleContainerization` with `AppleVm`. `runtime_label()` still returns `runsc` / `apple-containerization` and `token_injection_hook()` still returns `createRuntime`.
