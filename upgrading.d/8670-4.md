## The bare-host SSRF check is internal

**Startup:** no notice

**What you gain.** A smaller security surface: the URL check is the one public entry point, so its parsing rules cannot be bypassed by checking a host extracted some other way.

**What you lose.** The path `mcp_gateway::security::check_host_not_ssrf` no longer resolves.

**What you do.** Call `mcp_gateway::security::validate_url_not_ssrf` with the URL you are about to fetch. It applies the same host check.
