## A daily anonymous heartbeat

**Startup:** no notice, nothing changes at startup

What you gain: the author can count installs, versions and platforms. The
heartbeat carries five fields: `project`, `event`, the mcp-gateway version, the
operating system and architecture, and a random install id stored under
`heartbeat/` in the data directory. It is sent at most once per UTC day, after
the server starts and then hourly, never waits on startup or a request, and a
failure is ignored.

What you lose: nothing, unless you want no outbound connection the gateway
did not need for your configuration. Set `DO_NOT_TRACK=1` to turn it off. It
never sends from a development build, in CI, with `security.posture:
hardened`, or when `HTTPS_PROXY`, `HTTP_PROXY` or `ALL_PROXY` is set.
docs/PRIVACY.md, "Daily heartbeat", says what the receiver stores (a city name
and a country code from the connecting address, with the time) and that it
keeps records for three months.
