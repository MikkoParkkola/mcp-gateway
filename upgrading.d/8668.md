## One definition of each JSON-RPC error code in the library

**Startup:** no notice

What you gain: one place that defines each standard JSON-RPC error code
(`error::rpc_codes`), which every response the gateway builds now reads.

What you keep: every code on the wire. Clients see the same numbers as before.

What you lose: one name in the Rust library API.

| Removed | Use instead |
|---|---|
| `mcp_gateway::protocol::era::METHOD_NOT_FOUND_CODE` | `mcp_gateway::error::rpc_codes::METHOD_NOT_FOUND` |

What to do:

- Nothing, if you only run the gateway.
- In Rust code that links the library, rename the constant as above; its value
  is the same, -32601.
